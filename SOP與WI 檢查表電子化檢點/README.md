# SOP / WI 檢查表電子化檢點系統（C50110-INV-02-01）

將 **鴻勝化學科技股份有限公司《C50110-INV-02-01 儲槽進出貨作業方法（3.1版）》** 內全部 5 張檢點表全面電子化，支援現場手寫簽名、組長／課(副)長／品管常用簽名檔一鍵呼叫、視覺化改版與版本鎖定，以及 1:1 貼合原 WI 規格的 A4 PDF 與原生 Excel（`.xlsx` 含簽名圖）匯出。

## 核心功能亮點
- **檢點大廳（5 張全涵蓋）**：一進頁面即可選擇 `6.1 槽車泵料入儲槽檢查表`、`6.2 運輸油槽車安檢清潔度檢核表`、`6.3 ISO TANK 作業檢點表`、`6.4 ISO TANK 取樣作業檢點表`、`6.5 油罐車放櫃作業前檢點表`。
- **現場防呆與自動試算**：儲槽容積 `(A)-(B)=(C)` 與 `M/T` 溢槽警示、泵浦「＼ 無此項」快捷聯動、反向安全項（第 5 項選「是」亮紅必填原因）、接地線 ≤10Ω 與濾袋壓力 >2 Kg/cm² 自動警示。
- **多層簽核與常用簽名檔庫**：組長、課(副)長、品管人員可手寫存入或上傳簽名圖檔，往後點一下即可一鍵呼叫簽核（可選開 4 碼 PIN 防冒簽）。
- **模板編輯與一鍵升版（ISO 版本鎖定）**：可修改公司/表單編號/版別、動態增刪廠區下拉清單、切換匯出表頭廠區樣式（`☑/☐` 或 `廠區：XX`）與增刪項目；升版後歷史紀錄永久鎖定舊版面。
- **雙軌原格式匯出**：支援 A4 PDF 列印存檔與原生 ExcelJS `.xlsx`（含框線、合併儲存格與透明手寫簽名 PNG 圖片）。

## 快速啟動
1. **本機純網頁預覽**：直接雙擊 `1_Web_網頁版/index.html`。
2. **本機區網／平板 PWA 測試**：雙擊 `2_PWA_App版/啟動PWA本機測試.bat`，手機/平板掃描或輸入主控台顯示的區網 IP 即可安裝使用。
3. **部署 Cloudflare D1 雲端正式版**：於 `3_Cloudflare_D1版/wrangler.toml` 填入 `database_id` 後，雙擊 `一鍵自動部署上雲端.bat`。
