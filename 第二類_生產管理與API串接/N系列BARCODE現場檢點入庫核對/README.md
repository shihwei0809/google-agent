# 📦 N系列 BARCODE 現場作業檢點系統 (入庫核對版)

> **⚠️ 核心業務隔離聲明**：  
> 本專案為 **「入庫現場檢點系統」(Warehouse Receiving & Inspection)**，負責桶槽進廠檢點、外箱條碼有效期限解析推算、出貨地比對與四合一入庫一致性確認。  
> **請絕對不要與「N系列 BARCODE 出貨核對系統 (Shipping)」混為一談！兩者欄位順序、檢驗規則與存檔分頁截然不同！**

---

## 🎯 系統架構定位：入庫 vs 出貨 差異對照表

| 項目 | 📦 本專案：入庫現場檢點 (v51.1) | 🚚 出貨核對系統 (v34.6) |
| :--- | :--- | :--- |
| **主要業務情境** | 桶槽進廠入庫、現場檢點、效期核算 | 裝板出貨、繳庫單核對、防錯裝錯發 |
| **首欄位 (f0)** | **外箱條碼**（料號與保存期限條碼，1/7開頭） | **桶1 批號**（現場實體桶槽） |
| **桶槽欄位** | 包含「批號、出貨地、料號」（AZ含出貨地） | 僅「批號、料號」（無出貨地欄位） |
| **外箱條碼檢核** | **強制卡控**（首碼1需為20/24碼、首碼7需為29碼） | 無此卡控 |
| **效期推算比對** | 從批號解碼生產日，推算預期效期並比對箱標籤 | 無效期推算比對 |
| **單據比對項目** | 四合一單據 (4in1) | 四合一單據 + **繳庫單 (Warehouse Slip)** |
| **試算表存檔分頁** | `現場整板紀錄`、`現場AZ紀錄`、`現場散桶紀錄` | `整板出貨紀錄`、`混板出貨紀錄`、`AZ出貨紀錄`、`散桶出貨紀錄` |

## 🏷️ 條碼規格升級與雙軌相容機制 (2026-09 最新)

依據化學品 SVM Line 標籤規格變更通知，正式料號第 1 維條碼（首碼以 `1` 開頭）實施新舊雙軌卡控：

### 條碼結構對照表

| 欄位區間 | 舊版庫存規格 (As is - 20 碼) | 新版規格 (To be - 24 碼) | 說明 |
| :--- | :--- | :--- | :--- |
| **首碼 (Prefix)** | 第 1 碼：`1` | 第 1 碼：`1` | 固定開頭識別碼 |
| **料號 (Material)** | 第 2 ~ 10 碼（**9 碼**，不足補空白） | 第 2 ~ 14 碼（**13 碼**，不足補空白） | 支援長料號擴增 |
| **保存期限 (Expiry)** | 第 11 ~ 18 碼（**8 碼**，YYYYMMDD） | 第 15 ~ 22 碼（**8 碼**，YYYYMMDD） | **位置往後位移 4 碼** |
| **公司代碼 (Company)** | 第 19 ~ 20 碼（**2 碼**，如 TS / TW） | 第 23 ~ 24 碼（**2 碼**，如 TS / TW） | 結尾代碼卡控 |
| **總長度** | **20 碼** | **24 碼** | **系統同時放行檢核** |

### 核心相容邏輯代碼 (`processAndSave` - M76 嚴格 24 碼 / 其餘嚴格 20 碼)
```javascript
else if (prefix === "1") { 
  // 1. 自動偵測現場掃描的批號是否屬於 M76 儲槽
  var isM76 = false;
  for (var k = 0; k < f.length; k++) {
    if (toStr(f[k]).toUpperCase().indexOf("M76") !== -1) {
      isM76 = true;
      break;
    }
  }

  var lengthValid = false;
  if (isM76) {
    // 【M76 儲槽】：嚴格只能是 24 碼！
    if (len === 24) {
      lengthValid = true;
    } else {
      errorList.push('❌ [料號與保存期限條碼] 長度錯誤！<br>👉 M76 儲槽只能是 24 碼 (目前長度: ' + len + ')。');
    }
  } else {
    // 【非 M76 儲槽】：其餘一般儲槽嚴格只能是 20 碼！
    if (len === 20) {
      lengthValid = true;
    } else {
      errorList.push('❌ [料號與保存期限條碼] 長度錯誤！<br>👉 一般儲槽(非 M76)應為 20 碼 (目前長度: ' + len + ')。');
    }
  }

  if (lengthValid) { 
    // 動態根據長度計算截取位移
    var rD   = (len === 24) ? boxBarcode.substring(14, 22) : boxBarcode.substring(10, 18); 
    var mStr = (len === 24) ? boxBarcode.substring(1, 14).trim() : boxBarcode.substring(1, 10).trim();

    if (/^\d{8}$/.test(rD)) { 
      boxExpiry = rD; 
      boxMat = mStr; 
    } else {
      errorList.push('❌ 日期解析失敗！(抓取到的日期碼: ' + rD + ')'); 
    }
  } 
}
```

## 🚀 未來維護指引（當舊庫存全數消化完畢時）

當廠內 20 碼舊庫存全數出清，欲收斂為「純 24 碼規格」時：
1. **寫入邏輯 (`processAndSave`)**：
   * 將 `if (len !== 20 && len !== 24)` 改為 `if (len !== 24)`。
   * 將三元運算子簡化為固定截取：`boxBarcode.substring(14, 22)` 與 `boxBarcode.substring(1, 14).trim()`。
2. **歷史查詢 (`searchRecords`)**：
   * **強烈建議保留 20/24 碼判斷**，避免同仁翻查過去歷史紀錄時，舊資料料號產生截取位移錯誤。
