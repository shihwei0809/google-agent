# N系列BARCODE現場作業檢點 (入庫核對系統) 專案管理技能

本專案是「N系列BARCODE現場作業檢點（入庫核對）」的後端與檢點系統。

## ⚠️ 嚴格架構區隔警告 (AI 必讀)
1. **本系統為【入庫檢點】**：
   - 首欄位 `f[0]` 為外箱標籤（料號與保存期限條碼）。
   - 具有批號推算有效期限比對外箱條碼之檢點邏輯。
   - 存檔寫入工作表為 `現場整板紀錄`、`現場AZ紀錄`、`現場散桶紀錄`。
2. **絕不可與【出貨核對】混淆**：
   - 出貨核對專案位於 `N系列BARCODE出貨核對`，其比對繳庫單與四合一單據，無最前端外箱標籤檢核。
   - 在進行任何程式碼重構、維護或升級時，切勿將出貨邏輯套入本入庫系統，亦切勿將本系統之外箱邏輯覆蓋至出貨系統。

## 🛠️ 環境需求與指令
1. **Google Apps Script 雲端編輯器**：核心邏輯位於 `Code.gs`。
2. **部署方式**：透過 Google Apps Script「部署」>「管理部署作業」發布為 Web App。
3. **條碼規範**：支援首碼 1 之 20 碼（舊庫存）與 24 碼（新規格）雙軌相容驗證。
