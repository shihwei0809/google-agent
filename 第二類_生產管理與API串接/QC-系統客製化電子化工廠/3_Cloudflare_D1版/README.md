# 鴻勝化學 QC 檢驗即時看板系統 (PWA 雙軌獨立版)

鴻勝化學電子級化學品進出貨樣品登錄、T100 槽車排程智慧自動帶入、Microsoft Teams 精準分流通報與 2 小時超時預警看板系統。

## 🌟 核心特色與功能
- **🚛 T100 槽車排程智慧鎖定與自動帶入**：
  - 專門鎖定《明天進出貨排程報表(全部)20x3A00.xlsx》中「**明天進出貨排程報表(槽車)**」分頁。
  - 動態逐列狀態機掃描，同時提取上半部「出貨槽車 (10 車次)」與下半部「進料槽車 (10 車次)」，共 20 筆完整槽車排程。
  - 提供表單上方即時下拉選單，點選後**瞬間自動填入所有 9 欄位**，現場人員只需確認送樣單位與姓名即可一秒完成送樣！
  - 支援前端 SheetJS 即時上傳 / 拖曳新 Excel 檔案，秒級刷新當日排程。
- **📢 Microsoft Teams 精準分流通知 (Targeted Routing)**：
  - 徹底解決廣播通知洗版痛點！依據樣品「送樣單位 (`dept`)」動態路由。
  - 檢驗判定完成時，訊息**精準推送至【品管主管頻道】+【該送樣課室頻道】**（資材課、現場一課、現場二課、回收處理課）。
  - 其他非相關課室頻道完全靜音不被打擾。
- **🚨 2 小時檢驗超時智慧預警 (SLA Overdue Alert)**：
  - **前端視覺化**：看板即時動態計算等候時長，若等候超過 2 小時，自動轉為紅底呼吸燈閃爍動畫 `⚠️ 等候 X.X 小時 (逾期)`。
  - **雲端定時巡檢 (`Code.gs`)**：GAS 時間驅動觸發器每 10 分鐘自動執行 `checkOverdueSamples()`，超時樣品自動推播紅色 Teams 警報卡片，並透過 `isAlerted` 防呆標記防止重複洗版。
- **🧪 本機 PWA 獨立模擬測試箱與權限控管 (預設安全隱藏)**：
  - **預設隱藏保護**：現場同仁打開看板時，「🧪 本機模擬測試箱」工具列預設 100% 隱藏，不占用畫面空間，徹底杜絕誤觸風險。
  - **管理員 PIN 碼解鎖**：需點擊頂部「🔒 解鎖管理功能」按鈕並輸入 4 位數管理員 PIN 碼（預設 8888，可自訂）方可展開工具箱。
  - **一鍵重新鎖定**：測試完畢可隨時點擊「🔓 管理功能已解鎖」或「🔒 鎖定隱藏」重新安全上鎖。
  - 內建「⏱️ 注入逾期樣品 (>2小時)」、「🚨 執行逾期巡檢」、「⚙️ Teams Webhook 設定與卡片測試」。
  - 支援「高質感 Teams 互動卡片預覽視窗」，本機免聯網即可 100% 驗收分流目標頻道與卡片排版。
- **📱 PWA 雙軌架構標準 (方案一)**：
  - 支援電腦端 (Chrome/Edge) 與手機端 (Android/iOS) 一鍵安裝為獨立桌面 App。
  - 離線快取機制，即便斷網仍可流暢查看看板。
- **🔐 品管授權放行與實體標籤列印**：
  - 放行判定需輸入 4 碼 PIN 授權碼（由試算表後台管理）。
  - 支援一鍵開啟格式化 2 吋送樣標籤貼紙列印。

## 🚀 快速啟動與測試

### 1. 本機 PWA 測試 (支援手機同 Wi-Fi 連線)
雙擊根目錄之：
👉 `點我啟動PWA本機測試.bat`

系統將自動尋找可用 Port，並顯示：
- 電腦本機網址：`http://localhost:8010`
- 區域網路手機網址：`http://192.168.x.x:8010`

### 2. 雲端部署至 Cloudflare Pages
在 `2_PWA_App版/` 雙擊 `一鍵部署到Cloudflare.bat`，即可一鍵上線全球 CDN。
