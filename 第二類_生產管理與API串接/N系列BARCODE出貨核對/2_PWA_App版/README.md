# N系列出貨條碼核對系統 (PWA 獨立 App 版)

## 專案簡介
本專案為「N系列槽車出貨條碼核對」之現代化 PWA 應用程式版本，支援免商店一鍵安裝至桌面或手機主畫面、獨立全螢幕運行、離線快取與相機條碼掃描。

## 核心功能
- 📱 **PWA 獨立安裝**：電腦/手機一鍵「安裝為 App」，無網址列干擾
- 📷 **相機掃描條碼**：支援 HTML5 QR Code / Barcode 相機掃描
- ⚡ **雙軌記帳與離線支援**：內建 Service Worker，弱網環境秒開
- 🖥️ **一鍵啟動測試**：雙擊 `啟動PWA本機測試.bat` 自動開啟伺服器

## 快速啟動
1. 雙擊 `啟動PWA本機測試.bat`
2. 於瀏覽器點擊「安裝」或「新增至主畫面」
