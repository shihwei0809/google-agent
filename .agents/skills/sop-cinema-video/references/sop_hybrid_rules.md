# 企業 SOP 混剪防呆與電影後製規範 (`sop-cinema-video`)

## 1. 為什麼企業 SOP 強烈建議採「路線 B（混剪）」而非「純 AI 生片」？
- **真實介面不可替代**：AI 影片無法正確呈現公司實際系統畫面（鼎新 BPM、T100 ERP、QC 看板、遠通電收電子憑證專用章）。強行讓 AI 畫表單只會生出亂碼，同仁看完依然會填錯被退件。
- **最佳分工**：
  - **Flow Agent 微電影段（滿版 1920×1080 無厚框）**：負責「開場情境代入」、「常見錯誤痛點反轉」、「結尾交件／成果收尾」，建立電影節奏與記憶點。
  - **Python 高清實務段（保留既有驗證邏輯）**：負責實際欄位操作、日期/稅別對照卡、會計檢核清單。

## 2. 實務截圖 5 大品質底線（沿用 11/17 會計審核標準）
1. **個資自動馬賽克**：凡路線圖、身分證、聯絡電話或住家地址出現於截圖中，必須執行像素化遮蔽。
2. **禁止紅框干擾**：標註框不得使用純紅色（易與 ERP/BPM 表頭紅字或系統錯誤警示混淆），一律改用 **暗影壓暗聚光燈遮罩 ＋ 琥珀金 / 晴空青 / 翡翠綠雙層框**。
3. **高保真銳化**：文字與表格截圖縮放一律採用 **Lanczos 重採樣 ＋ UnsharpMask 邊緣銳化 ＋ FFmpeg `-crf 17`**。
4. **不寫死範例誤導**：所有截圖畫面內若含有範例金額、單號、公里數，字幕與旁白必須明確提醒「依個人實際憑證填寫」。
5. **移除測試標記**：正式輸出不得出現「鏡次 0x/08」或測試水印。

## 3. 電影化後製統一規格
- **標準尺寸**：`1920×1080`, `24 fps`, `yuv420p`, `AAC 44100Hz Stereo 192k`
- **片頭與片尾**：自動加入 3 秒緩推進電影海報「封面」與「封底」（支援外部 AI 海報圖，無圖時自動用 Pillow 生成深藍金邊質感海報）。
- **轉場**：禁用生硬 `concat -c copy` 硬切，統一採用 `xfade=transition=fade:duration=0.4` ＋ `acrossfade=d=0.4`。
- **Flow 影片疊層**：改採全畫面滿版鋪滿，僅在底部保留微透明玻璃浮動字幕條與右上角極簡章節膠囊，拆除厚重上下簡報邊框。
- **BGM 語音閃避 (`sidechaincompress`)**：放入 `bgm.mp3`（純無人聲配樂）時，自動套用 `threshold=0.03:ratio=6:attack=80:release=450`，旁白開口瞬間音樂柔和壓低、換氣或轉場時自動微幅浮現。

## 4. Colab 免費 T4 (15GB VRAM / 12GB RAM) 配音雙引擎規格
- **BreezyVoice**：隔離 Python 3.10 venv + `mtkresearch/BreezyVoice` (`d592c9d3`) + `MediaTek-Research/BreezyVoice-300M` (`e33b502e`) + `winstub` 免 pynini 直通。需 6–10 秒乾淨參考人聲；可自動透過 Whisper `small` CPU 補全參考逐字稿。
- **VoxCPM2**：隔離 Python 3.12 venv + `voxcpm==2.0.3` + `openbmb/VoxCPM2` (`32279eff`) + `optimize=False`（避開 T4 `sm_75` Triton 相容問題）。有參考音可克隆，無參考音可直接用文字描述設計聲線。
- **防爆規範**：TTS 生成必須在**獨立子程序**內跑完即退出，100% 釋放 12GB 系統 RAM 後，才啟動 `faster-whisper` 進行逐字驗音與挑選出最優 Seed。
- **台灣讀音正規化 (`normalize_tw_tts_text`)**：送進 Colab 前自動轉好 `A05→A零五`、`T01→T零一`、`eTag→一Tag`、`BPM→B P M` 與數字轉國字，並附 `TW_BOPO` 注音強制糾音表。
