# Google Flow Agent 電影分鏡與 Omni 1.2 Flash 省點公式

> 融合「阿玉 AI 短影片公式 v8」與企業 SOP 實務製作實戰基準。

## 1. 模型選用與點數鐵律（2026-11 最新）
- **首選模型**：**Omni 1.2 Flash**（11/08 釋出，人物一致性與中文發音顯著優於舊版）。
- **即將停用警告**：`Omni 1.1 Flash`、`Veo 3.1 - Fast`、`Veo 3.1 - Quality`（預計 12/05 停用），新專案一律改用 **Omni 1.2 Flash**（或 `Veo 3.1 - Lite`）。
- **省點黃金設定（點數打 3.3 折）**：
  - 生成時一律選 **360p**，下載成品時點擊 Flow 免費升頻至 **720p**！
  - Omni 1.2 Flash 點數對照（360p vs 720p）：
    - `10 秒`：**360p 只要 10 點**（720p 要 30 點）→ 免費帳號每日 50 點可穩生 **5 段**！
    - `15 秒`：**360p 只要 20 點**（720p 要 60 點）
    - `8 秒`：**360p 只要 8 點**（720p 要 24 點）
  - **張數永遠鎖定 `x 1`**，勿選 `x 2` 浪費兩倍點數。
- **注意模型特性**：`Omni` 模型原生只支援單張首幀參考；若該段落需要大跨度轉場（首幀＋尾幀雙圖插幀），Flow 會採用支援 Frames-to-Video 的模式，故指令包必須同時具備清晰的首幀描述 (`p0X-1`) 與尾幀描述 (`p0X-2`)。

## 2. 電影質感 5 大 Prompt 寫作規則
1. **先做「主角定妝照」（生圖免點數）**：
   - 多段影片務必先產出主要角色的 **正面、側面、背面三視圖定妝照**，鎖定臉型、髮型、衣著顏色與識別證配件，後續每個分鏡都必須註明「嚴格延續主角定妝照之外觀與服裝」。
2. **每段描述必須 150–200 字以上長篇細節**：
   - 嚴禁只有一兩句短詞！必須寫齊：**鏡頭焦段與角度**（如 35mm 電影鏡頭、低角度跟拍 / 緩慢推鏡）、**具體光線與色溫**（晨光逆光、辦公室內冷暖對比、陰影層次）、**材質與皮膚紋理**（織布紋理、車漆反光、髮絲光暈）、**背景景深**。
3. **檔案命名規範（方便 Flow Agent 一次打包下載）**：
   - 圖片：`定妝照`、`p01-1` / `p01-2`、`p02-1` / `p02-2` …、`封面`、`封底`
   - 影片：`v01`、`v02` …
   - 配樂：`BGM`
4. **避免在 AI 畫面內硬生複雜繁體中文字**：
   - 海報「封面」「封底」可放簡短 4–10 字主標（如「出差報帳不退件」）；至於表單欄位、車號、票號等細字，全部留給 Python 後製疊加或直接切進真實系統截圖。
5. **台灣國語配音策略**：
   - 雖然可在 Flow Prompt 寫入「請使用台灣中文發音」，實測若需長篇企業數字/法規旁白（如統編、13碼票號、T01/T02），**一律在後製抽換為本專案的「Colab T4 BreezyVoice / VoxCPM2 台灣克隆音軌」或「Gemini TTS」**，並讓 Flow 影片負責演出表情、動作與運鏡，做到零錯字、零大陸腔。
