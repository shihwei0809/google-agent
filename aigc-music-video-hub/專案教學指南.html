專案架構與工作流程

了解從音樂生成、故事板建立、影片渲染、到發佈至雲端空間的完整運作架構。

🔄 AIGC 影片生成與發佈流程圖

本機工作空間說明
  • 主開發目錄：位於 c:\GOOGLE ANGET\ai anget。所有程式碼修改、影片渲染和歌詞解析皆在此執行。
  • 發佈快取目錄：位於 c:\GOOGLE ANGET\aigc-music-video-hub。這是為雲端發佈優化過後的輕量資料夾，排除重複的圖片。
  • 本地共享圖片：位於 圖片/ 根目錄，共 41 張 PNG 檔案（34張廠區圖 + 7張弈融小宇宙圖），供所有 MVs 和網頁面板共用。
託管平台分工
  • Netlify（主要）：用於架設線上音樂影片播放網站。每月提供 100 GB 的流量，非常適合承載 MP4 影片與 MP3 播放。
  • Firebase Hosting（備用）：同樣配置於此專案，但其免費版每日限制僅 360 MB 流量，不適合用來公開播放影片，僅供備份。
  • Google Drive：直接映射同步本機檔案，用於內網備份與資料分享。

Netlify 雲端代管與發佈

了解如何查詢使用額度、連結網站、以及快速將最新的網頁與影片上傳部署到 Netlify。

⚠️

打包優化：請勿直接上傳整個專案！

專案包含 39 個子資料夾，每個資料夾若包含 34 張圖片將達 1.3 GB。為避免 Netlify 上傳逾時失敗，我們使用 dist 靜態打包，僅上傳網頁、音樂和 MP4 影片，其餘共用圖片（約 40 MB）放置於根目錄，總打包大小約 670 MB。

📊 查詢目前使用空間與流量

Netlify 的免費帳戶（Starter）採用信用額度制，每個月提供 **100 GB** 的免費頻寬（Bandwidth）。若要查看目前的實際使用額度：

  1. 登入您的 Netlify 網頁控制台。
  2. 進入您的專案團隊使用頁面：Netlify 使用量與帳單頁面
  3. 在 Bandwidth 項目即可看見目前已使用的流量百分比（每月自動歸零）。
🚀 CLI 快速部署與更新

當您在本機渲染了新影片或更新了面板，您可以使用以下指令，在短短十幾秒內將 dist 目錄發佈到線上：

# 1. 切換至發佈快取資料夾
cd "c:\GOOGLE ANGET\aigc-music-video-hub"

# 2. 執行指令將 dist 打包檔直接發佈至生產網頁
netlify deploy --dir=dist --prod
🔗 建立、重綁與切換 Netlify 網站

若您未來想變更部署的網站或綁定新的帳戶：

  • 查看目前連結狀態： netlify status
  • 綁定其他已存在網站： netlify link
  • 手動切換網站 ID： 編輯資料夾下的 .netlify/state.json，修改裡面的 "siteId": "您的網站ID"。

確認影片與音軌已更新

本機有新歌渲染時，確認對應的 _MV.mp4 檔案已存在。

執行 python build_mv_dashboard.py 更新本地 HTML。

Firebase Hosting 託管與發佈

了解 Firebase Spark 免費版的限額機制、如何查詢用量、以及如何部屬與變更設定。

🚨

重大流量警告：免費版每日僅 360 MB 頻寬！

Firebase Hosting 免費版 (Spark) 的下載頻寬為**每日 360 MB**。每部 MV 影片的大小約為 13 MB，這意味著如果有人完整播放 28 次，您的 Firebase 網站當天就會因為流量超標直接下線（報 509 Bandwidth Exceeded 錯誤），必須等到隔天中午才會自動恢復。因此強烈建議僅將其作為備份伺服器。

📊 Firebase 控制台用量查詢

Firebase 不會主動提醒您本日流量狀況，需至控制台手動查看：

  1. 登入 Firebase Console - aigc-music-video-hub
  2. 展開左側選單的 建置 (Build) ➔ Hosting
  3. 切換至正上方的 **使用量 (Usage)** 分頁。
  4. 此處會詳細顯示儲存空間（Storage，免費 10GB）與下載量（Downloads，免費每日 360MB）折線圖。
🚀 Firebase 部署指令

當需要手動發佈至 Firebase 時，請在工作根目錄 c:\GOOGLE ANGET 執行以下指令：

# 1. 登入 Google 帳號 (若過期)
firebase login

# 2. 僅部署 Hosting 資源
firebase deploy --only hosting
⚙️ Firebase 設定與排除規則

專案的 Firebase 配置存放在根目錄的 firebase.json 檔案中：

  • "public" : 指向發佈來源資料夾，目前配置為 "aigc-music-video-hub"。
  • "ignore" : 排除名單。為防範不小心將幾 GB 的原始圖片上傳至 Firebase 浪費其 10GB 儲存限額，我們已設定排除規則 "創作庫/**/圖片/**" 等。

本機音視頻自動化渲染

了解如何基於故事板 prompts.md、本機圖片和 FFmpeg 音軌，一鍵渲染出對齊長度的投影片 MV。

🛠️ 渲染引擎運作原理 (`render_all_custom_mvs.py`)

客製化投影片影片並不是套用一成不變的模板，而是動態產生的。其生成機制如下：

  1. 讀取故事板： 腳本掃描每個歌曲資料夾，讀取 vids_storyboard_prompts.md。
  2. 計算播放時長： 偵測音訊檔（MP3）的精確秒數，並除以故事板中的場景總數，計算出每張圖片顯示的平均秒數。
  3. 匹配本機圖片： 根據故事板記錄的圖片檔名，優先尋找歌曲資料夾下的 圖片/ 目錄，若沒有則 fallback 至根目錄的共用 圖片/ 目錄。
  4. FFmpeg 合成： 自動輸出 slideshow_inputs.txt 描述檔給 FFmpeg，利用 concat 濾鏡合併圖片，並將 AAC 高品質音軌封裝進 MP4 檔案中，在歌曲播完時自動結束。
💻 執行本機渲染指令

當有新歌加入，或圖片更新後需要重新渲染影片時：

python "c:\GOOGLE ANGET\ai anget\render_all_custom_mvs.py"
📝 投影片 concat 腳本語法範例

在影片合成時，產生的臨時 slideshow_inputs.txt 結構如下：

file 'c:/GOOGLE ANGET/ai anget/圖片/01_廠區遠景.png'
duration 7.9814
file 'c:/GOOGLE ANGET/ai anget/圖片/02_反應槽近景.png'
duration 7.9814
# 尾端重寫最後一張圖片，防範 FFmpeg concater 遺失最後一格時長
file 'c:/GOOGLE ANGET/ai anget/圖片/02_反應槽近景.png'

AIGC 網頁主控台面板維護

了解如何重新編譯主控台網頁，以整合新渲染的影片、更新歌詞匹配和修改曲風設定。

⚙️ 主控台編譯腳本 (`build_mv_dashboard.py`)

音樂影片專案總覽.html 是由 Python 自動編譯產生的。當您執行 build_mv_dashboard.py 時，它會自動完成以下工作：

  • 歌詞解析： 讀取並解析位於 創作庫/勝一與鴻勝化學_AI主題歌曲合輯.md 的總歌詞庫，依照章節編號（例如 1.1, 2.3.1）自動匹配到 39 個歌曲資料夾中。
  • 影片狀態檢驗： 掃描各子目錄，若有找到 *_MV.mp4 檔案則會在庫中寫入相對路徑，前台網站即會亮起「🟢 本機已生成」的播放按鈕，否則將隱藏按鈕。
  • 資料庫封裝： 將所有解析結果轉化為 JSON 資料庫，直接取代注入到 HTML 樣板底部（const songs = __SONGS_DATA_JSON__;），無須架設後端資料庫。
💻 重新生成網頁主控台

當歌詞庫檔案有異動、或有新渲染的 MV 影片要加入前台顯示時，請執行：

python "c:\GOOGLE ANGET\ai anget\build_mv_dashboard.py"
📁 共用圖片路徑優化

主控台的前端渲染目前已被我們優化為共用根目錄圖片。

  • 網頁中的故事板影像會直接加載 圖片/${scene.filename} 檔案。
  • 如此一來，在本機直接打開網頁（雙擊 音樂影片專案總覽.html），或是部署上線後，都能完美載入預覽大圖，且無需在每個子資料夾保留數百 MB 的重複圖片。

Google Drive 雲端同步備份

了解本機工作環境與 Google 雲端硬碟同步備份機制，確保資料安全且多端同步。

🔄 雲端備份機制工作原理 (`sync_to_gdrive.py`)

專案配置了 sync_to_gdrive.py 一鍵同步腳本。它能高效地比對本地磁碟與雲端硬碟中的檔案：

  • 智慧比對： 腳本會讀取檔案的大小與修改時間（mtime），若檔案完全一致則直接跳過，大幅縮短上傳時間。
  • 黑名單排除： 自動跳過 Python 虛擬環境 venv、Git 紀錄 .git 以及暫存目錄，避免上傳無用檔案。
  • 清理多餘檔案： 專案內已透過自動清理，將雲端硬碟中舊版的 *_Vids版.mp4 等過期母片和重複圖片子目錄清空，維持雲端儲存空間整潔。
💻 執行雲端硬碟同步指令

當您在本機完成了大批影片渲染或主控台更新後，可執行以下指令進行同步備份：

python "c:\GOOGLE ANGET\aigc-music-video-hub\sync_to_gdrive.py"
🚨 注意事項：請確保掛載 G 槽

在使用同步腳本前，請確認：

  • 電腦已安裝並啟動了 **Google Drive 電腦版應用程式**。
  • 雲端硬碟已被掛載為本機的 G 槽 (G:\我的雲端硬碟)。
  • 若掛載代號不同，需修改 sync_to_gdrive.py 中的 dest_dir 路徑。
