Windows 原生遠端桌面 (RDP 3389) 穿透指南

公司本機的 3389 埠目前已開啟並就緒，可透過 Cloudflare 穿透直連

步驟一：在您家中的電腦下載 Cloudflared

家中電腦若為 Windows，可直接下載官方免安裝程式：

點我下載 cloudflared-windows-amd64.exe

步驟二：在家中終端機啟動本地轉發

執行以下指令將公司遠端桌面映射到家中的本機 3389：

cloudflared access rdp --hostname [公司穿透網址] --url localhost:3389

步驟三：開啟 Windows 遠端桌面連線 (mstsc)

在電腦按 Win + R 輸入 mstsc，電腦名稱輸入 localhost:3389，即可順利開啟公司完整畫面！
