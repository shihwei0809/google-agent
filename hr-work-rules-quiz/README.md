# 員工教育訓練測驗系統 — 使用說明

## 📁 資料夾內容

```
hr_quiz_v2\
├── index.html              ← 主系統（簡報 + 測驗 合一）
├── apps_script_code.gs     ← Google Apps Script 程式碼
├── README.md               ← 本說明文件
├── 點我啟動內網伺服器.bat  ← 內網啟動器（Python 版，若電腦有裝 Python 時用）
├── 點我啟動內網伺服器(Windows內建無須Python).bat ← 內網啟動器（Windows內建版，免安裝 Python）
├── serve_intranet.ps1      ← 內網啟動器支援腳本
└── slides\
    ├── slide_01.png        ← 簡報第 1 頁（直接從 PPTX 匯出）
    ├── slide_02.png
    ├── ...
    └── slide_20.png        ← 共 20 頁
```

---

## 🚀 系統功能

- 員工開啟 `index.html` 即可使用，無需安裝任何軟體
- 簡報畫面 100% 來自「工作規則管理簡報.pptx」原始內容
- 內建語音朗讀（繁體中文），可調整速度（0.7x ~ 1.5x）
- 預設自動換頁，員工只需點一次「開始播放」
- 測驗完成後，姓名及作答結果自動寫入 Google Sheet

---

## 🔧 連接 Google Sheet（一次性設定）

### Step 1：建立 Google Sheet
前往 https://sheets.new 建立新試算表，命名「員工測驗紀錄」

### Step 2：開啟 Apps Script
試算表上方 → 擴充功能 → Apps Script

### Step 3：貼上程式碼
將 `apps_script_code.gs` 全部內容貼入，取代原有內容後存檔

### Step 4：部署
1. 點右上角「部署」→「新增部署作業」
2. 類型：網頁應用程式
3. 執行身分：我
4. 誰可以存取：所有人
5. 點「部署」→ 複製產生的 URL

### Step 5：填入 index.html
打開 `index.html`，找到這一行（約在第 340 行附近）：

```javascript
const APPS_SCRIPT_URL='YOUR_APPS_SCRIPT_URL_HERE';
```

將 `YOUR_APPS_SCRIPT_URL_HERE` 換成您剛才複製的 URL，存檔即可。

## 📊 Google Sheet 結構（自動建立）

系統會自動建立兩個工作表頁籤：

| 頁籤名稱 | 用途 |
|---------|------|
| 題目設定 | 人資人員在此調整題目（無需改 HTML）|
| 作答紀錄 | 員工每次送出後自動寫入一列 |

**作答紀錄欄位：**
時間戳記 ｜ 姓名 ｜ 第1題 ｜ 第2題 ｜ … ｜ 第10題

## 📝 如何修改簡報設定與題目

您完全不需要修改任何 HTML 程式碼，直接在 Google Sheet 的工作表上修改即可：

1. **修改簡報與朗讀語音**：直接在 **「簡報設定」** 頁，您可以修改每一頁的標題、投影片圖片路徑（若有換圖）以及對應的語音朗讀文字。
2. **修改測驗題目**：直接在 **「題目設定」** 頁，您可以修改題目、選項 A/B/C/D 與正確答案。

系統每次加載都會自動從雲端同步最新的內容。

## 🖥️ 部署方式與內網共享

本系統設計為**完全免安裝**，且同仁打開時不需要安裝任何軟體或 Python！

### 🌐 方式一：內網共享（最方便，手機與電腦皆可連線）
若您希望同仁直接連線到您的電腦進行作答，請在您的電腦上執行以下步驟：

1. **確保連線相同網路**：您的電腦與同仁的手機/電腦必須連線至同一個 Wi-Fi 或公司內部網路。
2. **啟動本機網頁伺服器**：
   - **如果您的電腦有安裝 Python**：請雙擊執行 `點我啟動內網伺服器.bat`。
   - **如果您的電腦沒有安裝 Python**：請雙擊執行 `點我啟動內網伺服器(Windows內建無須Python).bat`。
3. **查看連線網址**：視窗中會顯示綠色的網址（例如：`http://192.168.3.35:8000/index.html`）。請【勿】關閉該視窗。
4. **同仁開啟作答**：同仁只需在手機或電腦的瀏覽器（如 Chrome 或 Safari）輸入上述網址，即可直接開啟測驗並作答！
   > 💡 **重要觀念**：只有您的電腦（伺服器端）需要執行啟動批次檔，作答的同仁**完全不需要**安裝 Python 或任何程式，只需透過瀏覽器輸入網址即可。

---

### 🚀 方式二：GitHub Pages（雲端免主機）
您可以將整個資料夾上傳到 GitHub，並啟用免費的 **GitHub Pages** 服務，同仁即可隨時隨地透過網際網路開啟測驗。

---

### 💻 方式三：本機直接開啟（限單機使用）
同仁若直接雙擊 `index.html` 也可以開啟系統，但因為瀏覽器的安全限制，部分語音功能或網路連線可能會受到限制，建議使用上述的「內網共享」或「GitHub Pages」方式。

---

## 🔐 進階功能與安全機制

1. **設定面板管理員密碼驗證**：進入主畫面右上角的 ⚙️ 系統設定時，需輸入管理員密碼（預設為 `admin888`），防止使用者擅自修改設定。
2. **防刷鎖與互動簡報**：支援優先載入互動簡報 (iframe)，並加入「簡報/影片看畢解鎖」防刷鎖機制。
3. **語音朗讀速度擴充**：語速除了 `0.7x ~ 1.5x`，已擴充至 `1.8x 飛快` 與 `2.0x 極速`。

---

## ⚠️ 注意事項

1. `slides` 與 `slide_images` 資料夾必須與 `index.html` 放在同一個資料夾。
2. 語音功能與互動功能需要使用 **Chrome、Edge 或 Safari** 瀏覽器。
3. 若同仁作答後未成功寫入試算表，請在主畫面右上角點選 ⚙️ 系統設定（需密碼），確認 Google Apps Script 網址是否正確。
