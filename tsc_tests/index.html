🖨️ TSC 標籤列印終極測試包 (含 8 種排版與轉印法)

這 8 個測試擋涵蓋了所有可能的方向與尺寸設定，包含最後一個純圖片輸出大絕招。

⚠️ 測試前請確認：1.紙張選 USER 2.邊界選「無」

  • 👉 方案1：純橫式 90x50 (不旋轉)
  • 👉 方案2：直式紙張 50x90 + CSS 旋轉 90 度
  • 👉 方案3：不設定 @page 尺寸，完全交由印表機驅動 (USER) 決定
  • 👉 方案4：加大畫布至 100x60 以防邊界被裁
  • 👉 方案5：純橫式 90x50 (旋轉 90 度)
  • 👉 方案6：純橫式 90x50 (旋轉 180 度/顛倒)
  • 👉 方案7：純橫式 90x50 (旋轉 270 度/-90 度)
  • 👉 方案8：圖片轉印模式 (終極大絕招)
