# 勝一出貨排程管理系統 - 系統使用說明書

本系統為專為**勝一化工股份有限公司**設計的出貨排程整合平台，協助**業務**、**技服課**與**運輸商**進行三方資料對齊、自動查照司機資料、動態統計排程與快速查詢個人任務，並支援系統操作作業日誌與全功能手機版操作。

---

## 一、 系統帳號與權限對照表
系統內建三種角色權限，登入密碼預設皆為 `123`：

| 帳號 (Username) | 預設密碼 | 角色 (Role) | 權限範圍與可用分頁 |
| :--- | :--- | :--- | :--- |
| **`sales`** | `123` | 業務人員 (sales) | 全功能開放（總覽儀表板、業務專區、技服專區、運輸專區、查詢、作業日誌） |
| **`tech_mgr`** | `123` | 技服主管 (tech_manager) | 全功能開放（與業務權限相同，可編輯所有欄位與查看作業日誌） |
| **`transporter`** | `123` | 運輸公司 (transporter) | 開放：**「儀表板總覽」**、**「運輸商專區」**與**「手動單筆編輯」**。<br>（*限制：手動編輯時僅能修改運輸相關欄位如車牌、司機、電話與出車時間，其餘業務/技服欄位唯讀鎖定。*） |
| 技服人員姓名<br>(如: **`胡富閔`**, **`林聖龍`**) | `123` | 技服人員 (tech_staff) | 僅開放：**「技服個人查詢」**（登入後自動綁定姓名且唯讀，僅能查看個人日程） |

## 二、 系統基礎設定管理 (帳號與司機清單 Excel 維護)
為使人員免於修改複雜的資料庫 JSON 檔案，系統提供了兩個直覺的 Excel 檔案進行日常資料維護：

### 1. 使用者帳號管理 (帳號密碼管理.xlsx)
* **管理檔案路徑**：專案根目錄下的 **`帳號密碼管理.xlsx`**。
* **修改密碼/新增人員**：
  * 使用 Excel 直接開啟該檔案。
  * 找到要修改的人員，在「密碼」欄位直接輸入新密碼並存檔。
  * 亦可於表格下方空白列新增一行，填入「帳號」、「密碼」、「權限角色」（必須為 sales/tech_manager/transporter/tech_staff 之一）與「顯示名稱」，儲存即可。

### 2. 全域司機清單管理 (司機名冊管理.xlsx)
* **管理檔案路徑**：專案根目錄下的 **`司機名冊管理.xlsx`**。
* **司機與車牌資料維護**：
  * 開啟該檔案可直接編輯或新增司機的：*景山司機代碼 (B)、車牌 (C)、司機 (D)、電話 (E)、身分證號 (F)*。
  * **雙向同步機制**：
    1. 當您直接在 **`司機名冊管理.xlsx`** 中修改並儲存後，網頁上手動編輯輸入司機代碼時會**即時套用最新的車牌與電話**。
    2. 當業務上傳最新的勝一出貨 Excel 基準時，系統也會**自動解析出最新的司機清單並同步回寫更新 `司機名冊管理.xlsx` 檔案**，維持資料完全同步。
* **免重啟、即時生效**：上述兩個 Excel 檔案不論何時修改與存檔，網頁端在下一次進行操作或登入時會自動即時解析，**完全不需要重新啟動伺服器**。

## 三、 系統作業日誌管理 (Activity Logs)
為保障資料安全並留存異動軌跡，系統建立了完整的作業日誌系統：
* **記錄對象與動作**：
  1. **使用者登入**：記錄登入成功的帳號、角色與時間。
  2. **Excel 上傳匯入**：記錄哪位使用者上傳了業務、技服或運輸 Excel，以及成功比對匯入的筆數。
  3. **手動單筆編輯**：當使用者點選「編輯」儲存異動時，系統會**自動對照舊資料與新資料，詳細記錄變更了哪些欄位**（例如：「車牌:『KNB-3277』→『KNB-9999』」）。
* **檢視方式**：業務與技服主管登入後，可點選頂部 **「作業日誌」** 分頁，即時瀏覽最新 200 筆系統動作，並可隨時點選「重新整理」載入最新日誌。

## 四、 角色操作流程說明

### 1. 業務專區操作（首發上傳）
* **角色任務**：上傳最原始的基準出貨清單，建立當日或當週的排班基礎。
* **操作步驟**：
  1. 登入 `sales` 帳號，點選頂部「業務專區」分頁。
  2. 將勝一基準 Excel（包含 `空白班表` 工作表與 `司機清單` 工作表）拖放入上傳區域。
  3. 點選「解析並匯入基準資料」按鈕。
  4. 匯入後，系統將自動跳轉回儀表板，並在表格中呈現所有基準訂單。

### 2. 技服課專區操作（I 欄更新）
* **角色任務**：填寫「充填手」資訊並上傳至系統與業務資料庫核對合併。
* **操作步驟**：
  1. 登入主管帳號 `tech_mgr`，點選「技服課專區」。
  2. 上傳技服課 Excel（填有 I 欄 `充填手` 資訊）。
  3. 系統會顯示「比對預覽報告」，標示「比對成功」與「查無基準訂單（警示）」。
  4. 確認比對結果無誤後，點選「確認匯入並更新」。
  5. 系統會將比對成功的訂單更新 `充填手`，並忽略警示的訂單（如：自行新增的 `IPA HQ` 行程）。

### 3. 運輸商專區操作（J-O 欄更新）
* **角色任務**：填寫派車、出車資訊並上傳核對。
* **操作步驟**：
  1. 運輸商以 `transporter` 帳號登入，點選「運輸商專區」或直接在儀表板表格點選「編輯」。
  2. **手動編輯權限**：點選「編輯」後，系統會自動鎖定「指送地」、「品名」、「充填手」等業務/技服欄位（唯讀），僅允許運輸商修改車牌、司機姓名、電話與出車時間，修改儲存後系統會自動在後台寫入作業日誌。
  3. **Excel 上傳與代碼自動補齊**：上傳填寫完畢的運輸 Excel。若在 O 欄填寫了「景山司機代碼」，系統會自動至資料庫比對「司機清單」，自動填補對應的 `車牌` (J), `司機姓名` (K), `電話` (L) 資訊，省去手動鍵入並進行防呆。

## 五、 特色功能說明

### 1. 精準四欄位比對規則
當技服或運輸商上傳 Excel 時，因資料列順序或有變更，系統採取以下比對規則以尋找資料庫中對應的業務基準訂單：
* **第一優先級**：比對「出貨通知單單別號」 (Column A)。
* **第二優先級**：若單號為空，則同時比對 **`指送地` (D) + `品名` (E) + `預計到貨日期` (F) + `到貨時間` (G)**。
* 比對字串會經過標準化（去除所有空格、英文字母轉小寫、全形轉半形），確保對齊極佳的精準度。

### 2. 排程動態統計與日期過濾
在儀表板總覽，使用者可自主調整「顯示方式」：
* `當天 + 2天 (預設)`：僅顯示今天至後天的出貨單。
* `今天` / `顯示全部` / `自訂日期區間`。
* **排班統計**：總出貨數、技服完成率、運輸完成率會**完全根據當前選取的日期區間動態計算**，維持資料與統計的一致性。
* **智慧防呆回退**：當預設的 `當天 + 2天` 內無任何訂單時，系統會自動切換為 `顯示全部`，防止畫面呈現空白造成的測試困擾。

### 3. 技服人員快速日程查詢
* 技服課人員（如：`胡富閔`）以自己的姓名登入後，介面會鎖定在其姓名，並顯示美觀的「日程卡片」，顯示所有他負責的到貨時間、地點、品名與車輛司機，極大便利了廠區內手機隨手查詢。

## 六、 本機資料結構與維護說明
* **資料庫檔案**：本系統採用無 SQL 安裝需求的 `database.json` 儲存資料，位於專案目錄下。
* **備份與還原**：若需要備份資料，僅需複製該檔案與 `帳號密碼管理.xlsx`、`司機名冊管理.xlsx`；如需還原，覆寫回該路徑並重啟網頁服務即可。
