## 第一章：快速上手 (3 秒連線指南)

### 電腦端操作：
1. 進入專案資料夾 `family-file-hub`。
2. 雙擊執行 **`一鍵啟動.bat`**（或 `start_server.bat`）。
3. 控制台視窗開啟後，將自動顯示連線網址與 QR Code。

### 手機端操作：
1. **家中 Wi-Fi 環境**：開啟手機相機，掃描螢幕上的「**🏠 區網 QR Code**」。
2. **在外 4G/5G 環境**：開啟手機相機，掃描螢幕上的「**🌐 外網 QR Code**」。
3. 頁面開啟後，選擇或建立資料夾，點擊「📸 手機拍照/錄影原檔直傳」或「批次選擇照片/檔案」即可開始傳輸！

## 第二章：線上自訂與建立資料夾

1. 開啟手機網頁後，頂部會顯示現有的資料夾（例如：`一般檔案`、`爸爸`、`媽媽`、`孩子`）。
2. 點擊綠色的 **`+ 建立新資料夾`** 按鈕。
3. 跳出彈窗後，輸入自訂名稱（例如：`2026旅遊照片`、`媽媽工作檔`），按下「確認建立」。
4. 系統會自動為您建立該目錄並選定，後續上傳的所有檔案將會自動分類儲存至該目錄中！

## 第三章：100% 原圖無損直傳說明

本系統提供最高規格的二進位無損傳輸保證：
- **不經過任何瀏覽器 Canvas 壓縮或轉碼**。
- **完全保留原始高解析度與廣色域**。
- **完整保留 EXIF 拍攝參數**（包含相機型號、ISO、快門速度、GPS 定位等資訊）。
- 電腦端下載時可點選「**原檔下載**」取得完全一致的實體檔案。

## 第四章：區網與 4G/5G 外網雙模式

本系統配備雙重外網隧道備援機制：
- **🏠 區網 (Wi-Fi)**：適合在家使用，傳輸速度最快（網址如 `http://192.168.x.x:8080`）。
- **🌐 外網 (4G/5G)**：
  - **第一系統 (Ngrok Engine)**：原生支援 `ngrok.exe`，自動生成高穩定 `https://xxxx.ngrok-free.app` 網址。
  - **第二系統 (SSH Reverse Tunnel)**：自動備援生成 `https://xxxx.lhr.life` 網址，100% 避免 Cloudflare Error 1033。

## 第五章：進階 - 自訂固定外網設定 (4 種方法)

若您希望網址固定不變（免每次掃碼），可選擇以下任一方式設定：

### 方法 1：設定 `config.txt`（最推薦）
開啟專案資料夾內的 `config.txt`，填入您的固定網址：
```text
CUSTOM_WAN_URL=https://your-custom-domain.com:8080
```
儲存後重啟 `一鍵啟動.bat` 即可！

### 方法 2：綁定個人 Ngrok 帳號金鑰 (AuthToken)
在 CMD 執行：
```cmd
.\ngrok.exe config add-authtoken <您的Ngrok金鑰>
```

### 方法 3：Tailscale 虛擬私有網
電腦與手機安裝免費 Tailscale，將電腦 Tailscale IP 填入 `config.txt`：
```text
CUSTOM_WAN_URL=http://100.110.120.130:8080
```

### 方法 4：家用路由器 Port Forwarding
在路由器設定埠號轉發 8080，並在 `config.txt` 填入您的對外固定 IP 或 DDNS。

## 第六章：電腦實體檔案儲存位置與自訂硬碟路徑

### 1. 預設便攜儲存位置（隨專案移動）
預設情況下，實體檔案儲存位置**完全看 `family-file-hub` 放在哪裡執行**：
- 專案放在 `D:\family-file-hub` 時，檔案存於：`D:\family-file-hub\uploads\`
- 將專案移至 `E:\family-file-hub` 或隨身碟時，檔案自動存於：`E:\family-file-hub\uploads\`
- 雙擊 **`一鍵開啟電腦儲存資料夾.bat`**（或 `open_folder.bat`），將自動為您打開當前的 `uploads` 資料夾！

### 2. 自訂儲存至其他磁碟區 / 外接硬碟
如果您希望將檔案儲存至特定外接大硬碟（例如 `E:\PhotoBackup\`）：
1. 開啟專案資料夾內的 `config.txt`。
2. 新增或修改一行：
   ```text
   UPLOAD_FOLDER=E:\PhotoBackup
   ```
3. 儲存後重啟 `一鍵啟動.bat`，後續上傳的所有檔案與目錄將會自動寫入 `E:\PhotoBackup` 中！
