# SOP 互動簡報產生器 (SOP Interactive Builder)

本系統為「員工教育訓練測驗系統」的核心工具，用於將 PDF/DOCX 文件透過 AI (Gemini) 自動轉換為互動式語音簡報及測驗題庫。

## 開發與版本控制規則

為確保專案穩定運行與多人協作，本專案嚴格遵守 Git Flow 分支工作規則。

### 1. 分支結構與用途
- `main`：正式版，永遠保持可用狀態，**禁止直接在此分支開發**。
- `dev`：開發整合區，功能穩定後才 merge 回 `main`。
- `feat/xxx`：新功能開發，從 `dev` 開出，完成後 merge 回 `dev`。
- `fix/xxx`：Bug 修正，從 `dev` 開出，完成後 merge 回 `dev`。
- `hotfix/xxx`：緊急修正，直接從 `main` 開出，完成後**同時** merge 回 `main` 和 `dev`。

### 2. Commit Message 格式
```
<類型>(<模組名稱>): <簡短說明>

- 變更項目 1
```
可用類型：`feat` (新功能), `fix` (修正), `hotfix` (緊急修正), `refactor` (重構), `docs` (文件), `style` (格式), `rule` (規則設定)。

### 3. 日常開發流程 (收工規則)
每次開發完成（使用者說「收工」時），會自動執行：
1. 顯示今日完成項目表格。
2. 自動執行 `git add`、`git commit` 及 `git push`（預設推至 `dev` 分支）。
3. 顯示 GitHub 推送結果與連結。

### 💡 主要功能

1. **一鍵解析：** 上傳教育訓練文件 (PDF/DOCX/TXT)，AI 自動拆解為分鏡腳本。
2. **多語音引擎支援：** 
   - 內建高品質 Edge TTS
   - 支援 Gemini 2.5 Flash TTS 情感語音
   - **(NEW!) 支援本機 AI 克隆語音引擎 (`ai-voice-cloner-guide`)，可自訂專屬人聲配音。**
3. **互動測驗生成：** 自動根據 SOP 內容生成 3-5 題測驗，確保學習成效。
4. **一鍵產出：** 直接匯出成包含聲音、圖文、測驗的互動式 PPTX 檔案。

### 4. 版本發布流程 (發布版本規則)
當系統準備好上線給使用者時（使用者說「發布版本」時），會自動執行：
1. 將 `dev` 分支 merge 到 `main`。
2. 自動遞增版本號（例如 `v1.0` -> `v1.1`）。
3. 建立 Git Tag 並推送到 GitHub (`main` 分支)。
4. 顯示發布成功的版本資訊與更新內容。
