# 每日開工確認與同步規範 (Daily Start Check-in & Auto-Sync Protocol)

## 觸發條件
當每日系統時間更新，或偵測到使用者對話提及「開工」、「開始工作」或當天第一次互動時觸發。

## 執行步驟
1. **自動拉取與合併收工備份**：
   - 執行 `C:\GOOGLE ANGET\AutoStartWork.ps1` 拉取 GitHub `main` 及 `auto-backup` 分支。
2. **前次進度彙整與提醒**：
   - AI 需讀取 Git Log (`git log -1 origin/auto-backup --stat`) 檢查前次收工時間與修改之檔案清單。
   - 向使用者回報：「**[開工進度提醒] 上次收工時間為 [時間]，上次改動的檔案為：[檔案清單]，已自動為您合併。**」
3. **系統狀態回報**：
   - 當前日期與時間
   - 本地服務與背景任務運行狀態（如：HTTP Server 8000 / Python 服務）
4. **目標列出**：
   - 根據前次修改內容，給出今日建議推動之主目標，確認後開始執行。
