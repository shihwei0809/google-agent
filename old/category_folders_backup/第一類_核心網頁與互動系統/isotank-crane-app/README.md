# ISO Tank 45,633 m² 天車高架堆疊與車道配置系統

本專案提供 45,633 m² (13,800 坪) 基地導入 2 臺軌道式龍門吊 (RMG 天車) 進行 2~3 層高架堆疊之 1:1 向量視覺化互動系統，呈現 650～980 櫃巨大容量與兩條核心裝卸車道佈局。

## 環境需求與啟動方式
1. 本專案包含 `index.html`。
2. 執行 `./setup_env.ps1` 可一鍵啟動展示。
