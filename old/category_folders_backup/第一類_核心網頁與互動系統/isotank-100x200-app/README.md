# ISO Tank 100m x 200m (20,000 m²) 平面配置系統

本專案為獨立全新建立之 100m x 200m (約 6,050 坪) ISO Tank 停車場配置系統，包含右下角藍框出入口與 150+ 格帶號碼車位。

## 環境需求與啟動方式
1. 本專案為獨立靜態網頁系統，包含 `index.html`。
2. 執行 `./setup_env.ps1` 可一鍵啟動本機伺服器展示。
