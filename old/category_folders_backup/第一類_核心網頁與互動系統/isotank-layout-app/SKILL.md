# ISO Tank 45,633 m² 廠區平面配置互動系統

本專案提供 45,633 m² (約 13,800 坪) ISO Tank 專用廠區之互動式平面配置圖與 240 格帶號碼車位 (A-01 ~ D-60) 即時管理展示系統。

## 環境需求與啟動方式
1. 本專案使用靜態 HTML5 + CSS3 + Modern JS 打造，無須複雜後端即可直接運行。
2. 開發或展示時，可執行 `./setup_env.ps1` 自動啟動本機伺服器。
3. 主程式入口為 `index.html`。
