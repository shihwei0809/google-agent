# 🎙️ NoType — AI 語音輸入工具 (用說的取代打字)

NoType 是一款為 Windows 設計的 AI 語音輸入小工具。只需按住快捷鍵（預設為 `Left Alt + Space`）開始說話，放開按鍵後即會自動將語音轉換為繁體中文，進行 AI 潤飾並自動貼到當前游標位置，實現極速、精準的「免打字」輸入體驗。

---

## 🌟 核心特色

1. **按住即說，放開即貼**：全域快捷鍵支援。按住組合鍵啟動錄音，放開時自動觸發 API 辨識與模擬鍵盤貼上，完全不打斷思維。
2. **現代膠囊波形提示框**：螢幕底部中央懸浮的半透明膠囊設計，說話時會有對稱的實時音量波形跳動與呼吸動畫，清楚感知錄音狀態，精美且不佔空間。
3. **雙核心語音辨識 (STT) 引擎**：
   - **OpenAI Whisper API** (`whisper-1`)
   - **Groq Whisper API** (`whisper-large-v3-turbo`，速度極快且提供免費額度)
4. **智慧音訊與誤觸過濾**：內建音量監測（VAD）與長度判斷。當錄音時間短於 `400ms`（防止誤觸）或最大振幅低於 `0.02`（無說話之背景雜音）時，會自動判定為靜音，直接忽略請求，**有效防止 Whisper API 產生幻覺文字並節省 API 額度**。
5. **Whisper 提示詞優化**：預設帶入繁體中文與標點引導，從源頭提升台灣口音與常用詞彙的辨識精準度。
6. **AI 文字潤飾 (LLM)**：可啟用 GPT-4o-mini 或 Llama 3.3 引擎，自動移除口語贅詞（如：那個、嗯、啊、然後等）、修正文法與自動排版標點。
7. **背景無痕啟動**：提供 `start-hidden.vbs` 啟動腳本，完全隱藏 CMD 視窗，讓程式在背景默默啟動並常駐於 Windows 系統工作列（System Tray）。

---

## 🛠️ 技術架構

- **外殼框架**：Electron (CJS 格式，結合 Tray 系統匣與 Web UI 設定頁面)
- **音訊處理**：MediaRecorder API (`audio/webm;codecs=opus` 高度壓縮格式，檔案體積小 10 倍以上)
- **底層介接**：`koffi` (純 JS FFI，呼叫 Windows `GetAsyncKeyState` 與 `keybd_event` API 進行鍵盤模擬與物理按鍵監測，無須 C++ 原生編譯)
- **設定儲存**：`electron-store` v8 (本地 JSON 設定存儲，金鑰不外洩)

## 🚀 快速開始

### 開發與啟動
1. 在專案目錄下安裝依賴：
   ```bash
   npm install
   ```
2. 啟動開發者模式：
   ```bash
   npm start
   ```

### 使用者一鍵啟動 (Windows)
專案內建兩個快速啟動檔：
- **`start.bat`**：雙擊即可透過 CMD 視窗啟動專案。
- **`start-hidden.vbs`**：雙擊可**在背景隱藏 CMD 視窗啟動**，程式只會出現在右下角系統匣，提供無痕極佳體驗。

### 專案打包
編譯為免安裝可攜版 (`NoType-Portable-1.0.0.exe`) 或安裝檔：
```bash
npm run build
```

---

## ⚙️ 設定說明
啟動程式後，於 Windows 右下角系統匣對麥克風圖示點擊**右鍵 -> 設定**，可開啟設定面板：
- 填入你的 **OpenAI API Key** 或 **Groq API Key**。
- 切換使用的 STT 引擎與 LLM 潤飾引擎。
- 自訂全域錄音快捷鍵（點擊框後按下你想要的組合鍵）。
- 設定是否開啟 AI 文字潤飾、開機自動啟動或僅複製至剪貼簿等功能。
