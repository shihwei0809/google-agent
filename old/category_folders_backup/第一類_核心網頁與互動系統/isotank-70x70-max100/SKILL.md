# ISO Tank 70m x 70m (4,900 m²) 極致 100 格車位系統

本專案為完全獨立建置之 70m x 70m (約 1,482 坪) 正方形廠區系統，針對極致蜂巢高密度連停法進行設計，提供 100 格獨立編號車位與右下角藍框出入口。

## 環境需求與啟動方式
1. 本專案為獨立靜態網頁系統，包含 `index.html`。
2. 執行 `./setup_env.ps1` 可一鍵啟動本機伺服器展示。
