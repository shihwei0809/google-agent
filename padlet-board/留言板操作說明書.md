# 📋 鴻勝化學 - 雲端協作留言板操作說明書

本留言板系統是一款專門為同仁開發的**雲端協作看板**（類似 Padlet 系統）。同仁可在此看板上即時進行資訊共享、通報品質異常、發布最新 SOP 規章、記錄稽核巡檢點檢，以及追蹤改善進度。

4. 系統會顯示「需要授權」對話框，點選 **「審閱權限」**。
5. 選取您的 Google 帳戶 (`shihwei0809@gmail.com`)。

10. 開通後，請將上方工具列的選取函數切換回 **`doGet`** 並再次點選「執行」一次，確保一切運作皆正常。

## 💻 第二階段：日常功能操作指南

### 1. 識別雲端同步狀態 (看左上角燈號)
網頁左上角 `CollabBoard` 圖示旁設有**狀態指示燈**，讓您隨時掌握資料同步狀態：
* ☁️ **雲端已同步** (綠色)：代表您剛剛的新增、編輯、留言或點讚，已 100% 寫入雲端資料庫。
* 🔄 **同步中...** / **載入中...** (黃色/藍色)：代表系統正在與雲端伺服器通訊，請勿關閉網頁。
* 🔌 **本機模式** / ⚠️ **同步失敗** (灰色/紅色)：代表網路斷線或權限失效，此時資料會暫存於您的瀏覽器中。

## 🖼️ 第三階段：卡片圖片上傳與網址使用教學

為了讓同仁在張貼品質異常、巡檢照片時能順利顯示圖片，系統提供了非常友善的圖片功能：

### 1. 直接本機上傳圖片（最簡單、免複製連結 ⭐）
同仁可以在新增或編輯卡片時，直接上傳手機或電腦裡的圖片：
1. 在卡片表單中，點選圖片欄位右側的 **「上傳圖片」** 按鈕。
2. 選擇您要上傳的相片檔案（支援一般常見的手機或電腦圖片格式，單張檔案限制 **10MB** 以內）。
3. 系統會顯示 **「圖片上傳至雲端硬碟中...」**，上傳完成後，系統會自動在圖片欄位填入上傳後的 Google Drive 連結，並顯示預覽。
4. 點擊卡片右下角的 **「張貼」** 或 **「更新」** 即可送出！
   > [!NOTE]
   > - 圖片將統一儲存至管理員 Google Drive 內自動建立的 **「留言板圖片」** 資料夾中，同仁無須登入其個人 Google 帳戶即可直接上傳。
   > - 管理員可以在此資料夾中進行圖片的檢視與整理。

---

### 2. 圖片連結自動轉換（推薦使用 Google 雲端硬碟 ☁️）
如果您的圖片儲存在 Google 雲端硬碟，同仁只需完成以下簡單步驟：
1. **上傳圖片** 到您的 Google 雲端硬碟。
2. 右鍵點選該圖片 -> 選擇 **「共用」 (Share)**。
3. 將「一般存取權」從限制改為 **「知道連結的任何人」 (Anyone with the link)**，且角色設定為 **檢視者**。
4. 點選 **「複製連結」**。
5. **直接貼入留言板** 的 「圖片網址」 欄位！
   > [!TIP]
   > **系統已內建自動轉換功能**！同仁不需要手動轉換複雜的 Google Drive 圖片連結。只要將標準的共用連結（例如：`https://drive.google.com/file/d/.../view?usp=sharing`）貼入，系統會自動在後台將其轉換為可直接顯示的圖片網址。

---

### 3. 使用免費線上圖床（無雲端硬碟時的備用方案）
  如果不想使用雲端硬碟，也可以使用免費且無須註冊的線上圖床：
  * **Postimages 圖床**：
    1. 開啟 [Postimages 官方網站](https://postimages.org/)。
    2. 點擊「選擇圖片」並上傳您的手機或電腦照片。
    3. 上傳成功後，複製 **「直接連結」 (Direct Link)**（網址結尾為 `.jpg` 或 `.png`）。
    4. 將此網址貼入留言板的 「圖片網址」 欄位。
  * **SM.MS 圖床**：
    1. 開啟 [SM.MS 官方網站](https://sm.ms/)。
    2. 將圖片拖入上傳區，點擊 **Upload**。
    3. 上傳後，在下方取得 **Image URL** (或 URL) 並複製.
    4. 貼入留言板的 「圖片網址」 欄位。

---

### 4. 從通訊軟體直接獲取圖片網址（最直覺）
如果圖片已經傳送到公司的 LINE 或 Microsoft Teams 等通訊軟體：
1. 在對話框中的圖片上點選 **滑鼠右鍵**。
2. 選擇 **「複製圖片網址」 / 「複製連結」** (注意：不是複製圖片，是複製網址)。
3. 貼入留言板的 「圖片網址」 欄位即可！

## 🤖 第四階段：AI 智慧助理「小鴻」與語音輔助功能

為了提升廠區巡檢與異常通報的效率，系統無縫整合了 **Google Gemini AI** 與 **Web Speech 語音辨識技術**。同仁可透過 AI 智慧助理「小鴻」進行語音通報、文本潤飾、5-Why 診斷與看板問答。

### 1. ⚙️ 設定 Gemini API Key
* 點擊右下角（或頂部）的 **「AI 助理」** 按鈕滑出對話側邊欄。
* 點選側邊欄標題右側的 **`⚙️` (設定)** 按鈕。
* 貼入您的 **Gemini API 金鑰** (格式為 `AIzaSy...`) 並點擊 **「儲存設定」**。
* **確認狀態燈號**：
  - 🟢 **服務就緒**：代表金鑰驗證成功，可正常使用所有 AI 功能。
  - 🔴 **金鑰未設定**：此時無法執行 AI 分析與問答。
  > [!NOTE]
  > API Key 僅儲存於同仁自己電腦的瀏覽器中（`localStorage`），直接與 Google 官方 API 通訊，絕不上傳到任何第三方伺服器，確保鴻勝化學的商業機密與品質資料安全無虞。

---

### 2. 🎙️ 🎙️ 語音辨識輸入 (Speech-to-Text)
* **卡片內容語音通報**：
  1. 在新增或編輯卡片時，點選卡片內容輸入框旁的 **`🎙️ 語音輸入`**。
  2. 瀏覽器若彈出權限提示，請選擇 **「允許使用麥克風」**。
  3. 按鈕文字會顯示 **「聆聽中...」** 並亮起紅色呼吸燈，此時請對著麥克風口說描述異常（如：「*A線輸送帶剛才發生瓶蓋漏封，已緊急停機調整*」）。
  4. 說完後點選 **「停止」** 或靜止數秒，系統會自動將語音辨識為繁體中文文字並填入內容欄位中。
* **側邊欄語音提問**：
  - 點選對話框輸入欄右側的 **`🎙️`** 麥克風圖示，即可用語音對「小鴻」進行問答提問。

---

### 3. ✨ AI 文本編輯選單 (自動格式化與摘要)
在卡片編輯視窗中，同仁若是輸入了雜亂、口語的隨手筆記，可以使用輸入框上方的 **AI 文本編輯功能**：
1. **輸入草稿**：在卡片內容框中輸入口語化描述。
2. **選取處理類型**：
   * **✨ AI 潤飾 (Polish)**：自動將雜亂口語重新排版成專業三段式品保通報（【異常現象與描述】、【暫定影響範疇】、【建議處置與即時圍堵措施】）。
   * **📋 條列化 (Bullet Points)**：提煉精簡要點，自動轉換為條列式項目符號。
   * **🔍 總結摘要 (Summarize)**：自動壓縮成 120 字以內的主管摘要。
3. **點擊「執行」**：AI 會即時改寫框內文字並回填。確認無誤後點擊「張貼/更新」即可送出！

---

### 4. 🧠 一鍵 AI 5-Why 異常診斷
* **功能說明**：對於看板上的任何品質異常通報卡片，同仁只要點選卡片底部的 **`🤖 AI 診斷`** 按鈕。
* **動作流程**：小鴻會自動讀取該卡片的標題與詳細內容，進行 **5-Why 根因推導** 與 **長期預防 CAR (改善對策) 建議**，並自動以 **`🤖 小鴻`** 署名，將診斷結果張貼為該卡片下方的討論留言。

---

### 5. 💬 看板上下文感知問答
* 點擊右下角開啟對話側邊欄，AI 助理「小鴻」會自動收集**當前日期看板上的所有欄位、卡片標題、通報內容與留言**作為背景。
* 同仁可以像真人對話般，直接向小鴻詢問看板狀態。
  - *例如*：「*今天有什麼品質異常通報嗎？*」、「*目前的 S4 與 S5 稽核巡檢結果如何？*」、「*整理今天所有的 CAR 改善項目*」。

## 🔍 故障排除與注意事項 (Troubleshooting)

### Q1：開啟網頁時，左上角一直顯示「⚠️ 同步失敗」或「🔌 本機模式」，如何解決？
1. **未完成權限授權**：請確認您已完成本說明書的 **【第一階段：管理員初次開通設定】**。
2. **Google 帳號衝突（最常見原因）**：
   - 當瀏覽器同時登入多個 Google 帳號（例如個人與公司帳號）時，Google 會因 Session 混亂而拒絕連線。
   - **解決方法**：請使用瀏覽器的 **「無痕視窗 (Incognito)」** 開啟 Netlify 網址，即可順暢同步！
   - 同時，如果只是要展示，可以考慮點擊右上角「資料管理 -> 匯出備份」下載備份檔，再手動分享。
3. **無網際網路連線**：請檢查您的網路狀態。
