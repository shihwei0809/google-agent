專案 03

🚀 Clasp + Netlify 部署指南

前端 Netlify + 後端 Google Apps Script，透過 Clasp CLI 建立完整的自動化部署閉環，一套指令完成全棧推送。

# ── 後端 GAS 部署 ──────────────────
$ clasp login
$ clasp create --title "PadletBot" --type webapp
$ clasp push
$ clasp deploy --description "v1.0 production"
 
# ── 前端 Netlify 部署 ──────────────
$ netlify login
$ netlify init
$ netlify deploy --prod --dir ./dist
 
# ── 環境變數注入 ───────────────────
$ netlify env:set GEMINI_API_KEY $KEY
$ netlify env:set GAS_ENDPOINT $URL
 
# ── 一鍵全棧更新腳本 ───────────────
$ ./deploy.sh --all
 
✓ GAS deployed → script.google.com/...
✓ Netlify live → hongsheng-board.netlify.app
