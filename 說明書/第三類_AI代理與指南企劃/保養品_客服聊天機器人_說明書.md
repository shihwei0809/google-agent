# 保養品 客服聊天機器人 - 操作說明書

> 🔗 **GitHub 專案庫**：[shihwei0809/google-agent](https://github.com/shihwei0809/google-agent)


## 專案簡介
本專案為保養品智能客服問答與商品推薦機器人，能引導顧客進行肌膚檢測，並基於 Gemini/Groq API 進行個性化的保養品搭配推薦。

## 主要功能特色
- **多輪肌膚對談**：引導式問答（乾性/油性肌膚、敏感程度等）。
- **商品知識庫檢索**：自動比對後台商品清單進行精準推薦。

## 技術棧
- HTML, CSS, JavaScript, Gemini API / Groq API

## 操作步驟
1. 於 `保養品` 目錄下開啟 `index.html`。
2. 在交談視窗中輸入如：「我的皮膚很容易出油，有沒有推薦的保養品？」，機器人會自動引導分析並推薦產品。
