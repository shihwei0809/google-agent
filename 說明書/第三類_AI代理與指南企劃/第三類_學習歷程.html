里程碑 02

🎙️ 語音辨識的挑戰

Web Speech API 在工廠噪音環境下的準確率比我想像的高，但要處理 斷句還是花了很多心思。

踩坑紀錄

原以為語音辨識很簡單，結果連中文標點符號都要自己處理。

「說話」→ 「說 話」（斷詞錯誤）
「繼續」→ 「機修」（聽錯字）
「API」→ 「阿批愛」🤣

最後用 AI 後處理文字，把語音辨識結果再潤飾一次，才解決了大部分問題。那種「用AI修AI的錯」的感覺很奇妙。

// 語音辨識後處理
recognition.onresult = (event) => {
const raw = event.results[0][0].transcript;
 
// 直接送出？不行，錯很多
// 先問 Gemini 幫我潤飾
const polished = await polishText(raw);
 
// 「阿批愛」→「API」✓
return polished;
};
 
// Prompt 設計
const prompt = `
修正以下語音辨識文字，
保留語意，修正錯字與斷句，
輸出繁體中文：${raw}`;

里程碑 03

🏫 第一次串接官方 API

第一次用 OAuth 串接 Google 官方 API，終於理解了 Token 和 Scope 的概念。

理解的瞬間

我一直搞不懂為什麼要用 OAuth，直到我自己去串 Classroom API，才明白：

Token = 「我是誰」的證明
Scope = 「我被允許做什麼」
Refresh Token = 「不要每次都叫我重新登入」

第一次成功呼叫 API、看到自己建立的課程出現在 Classroom 上，那種感覺比任何一次考試滿分都興奮。

里程碑 04

🚀 學會讓AI部署自己

「現在我叫 AI 把程式推上去，牠真的會自己去做。」

部署日記

以前部署就是打開 FTP，手動上傳、手動改設定、然後祈禱沒壞。

現在我寫了一個 deploy.sh 腳本，裡面呼叫 clasp 推 GAS、netlify CLI 推前端，整個流程 12 秒搞定。

最爽的是我請 Claude 幫我寫這個部署腳本，然後用它部署，讓 AI 幫我把 AI 的程式推上去。AI 自我部署，有種說不出的哲學感 😂

clasp CLI Netlify Shell Script CI/CD
#!/bin/bash
# deploy.sh — 這是 AI 幫我寫的
# 然後我用它來部署 AI 的程式 🤯
 
echo "🚀 開始部署..."
 
# 後端：推到 Google Apps Script
clasp push && clasp deploy \
--description "$(date '+%Y-%m-%d %H:%M')"
 
# 前端：推到 Netlify
netlify deploy --prod --dir ./dist
 
echo "✅ 部署完成！耗時 ${SECONDS}s"
💡 這件事讓我學到
  • ▸ 自動化不是懶，是把精力留給真正重要的事
  • ▸ 好的腳本比文件更有說服力
  • ▸ 請 AI 幫你寫工具，再用工具幫你做事
