Clasp + Netlify 部署指南
讓 AI Agent 自動完成「前端推 Netlify + 後端 GAS 推 clasp」的完整部署閉環
# 1. 安裝工具
npm install -g @google/clasp netlify-cli

# 2. 登入授權
clasp login   # Google 帳號授權
netlify login  # Netlify 帳號授權

# 3. 一鍵部署 (Agent 自動執行)
clasp push                   # 推送 GAS 後端
netlify deploy --prod       # 推送前端

edge-tts 語音合成

🎬
FFmpeg 自動混音合成
照片序列 + 旁白 + 背景音樂，一行指令輸出 MP4
🔄
流程可複用
任何「圖片 + 文字 = 影片」的場景都適用，例如公司教材配音

python generate_narration.py

# 第二步：合成影片
python mux_video.py

# 輸出：renders/ 資料夾
graduation_trip_v1.mp4 ✅

垂直領域 AI 客服
保養品客服聊天機器人
把品牌知識庫餵給 AI，讓它扮演熟悉產品的專業客服，自動回答成分、功效與使用方式
🧬 知識庫設計
