# 跨電腦一鍵備份與還原轉移系統 (Backup & Sync System)

> 🔗 **GitHub 專案庫**：[shihwei0809/google-agent](https://github.com/shihwei0809/google-agent)


本系統是為 AI Agent (如 Anti-Gravity, Claude Code 等) 與本機開發環境量身打造的**跨電腦一鍵移植與備份方案**。它解決了電腦壞軌、系統損毀或轉移新電腦時，需要重新配置技能、設定與環境授權的痛點。

---

## 🛠️ 核心功能

1. **一鍵備份技能與授權 (Local to Google Drive)**：
   - 備份全域設定（包含 API Keys 與 MCP 配置）：`C:\Users\<Username>\.gemini\config\`
   - 備份 Anti-Gravity 提示詞技能：`C:\Users\<Username>\.gemini\antigravity\skills\`
   - 備份 Anti-Gravity 使用者設定：`C:\Users\<Username>\.gemini\antigravity\user_settings.pb`
   - 備份本機工作區技能：`C:\GOOGLE ANGET\skills\`
   - 備份檔將自動上傳至 Google Drive 的 `GOOGLE ANGET/skill-backup` 目錄。

2. **一鍵自動排程 (Monthly Auto-Backup)**：
   - 在 Windows 工作排程器註冊 `AntiGravity_Monthly_Backup` 任務，於每個月 1 號中午 12:00 自動在背景執行備份，免去手動操作。

3. **跨電腦一鍵還原 (Environment Auto-Setup)**：
   - 自動偵測並透過 Windows `winget` 安裝 Git、GitHub CLI、Node.js、Python 等必備軟體。
   - 自動安裝 Obsidian MCP (MCPVault)、NotebookLM 等 MCP 套件。
   - 自動將 Google Drive 的 `skill-backup` 還原到新電腦對應的 AppData 與本機工作區目錄，實現 100% 技能無痛轉移。
   - 自動引導 GitHub、Firebase 與 NotebookLM 的登入驗證。

## 🚀 操作說明

### A. 首次設定排程
1. 雙擊執行 `一鍵設定排程.bat`。
2. 系統會自動請求系統管理員權限，並於 Windows 排程器中註冊每個月 1 號中午 12:00 的自動備份工作。

### B. 手動執行備份
1. 雙擊執行 `一鍵備份技能.bat`。
2. 備份完成後，請確保 Google Drive 電腦版客戶端正在運行，檔案將會自動同步至雲端。

### C. 雲端資料夾備註 (手動步驟)
由於 Google Drive API 的限制，建議您在瀏覽器上登入 Google Drive 網頁版，在 `GOOGLE ANGET` 資料夾上點擊右鍵選取「詳細資料」/「新增描述」，備註如下：
> 「此資料夾存放 Anti-Gravity AI Agent 的技能與設定備份。轉移新電腦時，將此資料夾下載後即可點擊還原。」

### D. 轉移至新電腦
1. 在新電腦上安裝 **Google Drive 電腦版**，並登入您的 Google 帳號。
2. 將雲端的 `GOOGLE ANGET` 目錄同步或下載至新電腦的 `C:\GOOGLE ANGET`。
3. 進入 `C:\GOOGLE ANGET` 目錄，按右鍵以「系統管理員身分執行」`setup_new_computer.ps1`，或使用 PowerShell 執行它。
4. 腳本會引導完成所有軟體安裝、備份檔還原以及帳號授權，完成後重啟 AI 即可使用所有自訂技能！
