## 專案簡介
本專案為彰濱廠與崙尾廠 IPA 電子級化學品生產排程、槽位進耗存平衡、日報重量自動換算與產銷模擬之旗艦級整合系統。採用 **Cloudflare Pages Advanced Mode (`_worker.js`) + Cloudflare D1 Database** 雲端架構，徹底解決跨電腦資料同步問題，支援即時試算、產銷排產、赤字累積計算與多分頁 Excel 日報一鍵匯入。

---

## 核心功能特色
1. **Cloudflare D1 跨電腦即時秒同步 (Advanced Mode)**：
   - 透過 `public/_worker.js` 與 `_routes.json` 直連 Cloudflare D1 邊緣關聯資料庫（`ipa-pwa-db`）。
   - 在任何電腦、手機或平板開啟網頁，修改儲槽排程或產銷數據後點擊儲存，雲端即刻同步，徹底杜絕跨機資料不同步與白屏問題。
2. **日報 Excel 多分頁直接匯入**：
   - 整合 SheetJS 離線解析器，可直接匯入 `儲槽作業日報表.xlsm`。
   - 自動秒讀解析 `10.1`、`10.8`、`10.12` 等多個工作表，自動抓取 08:00 各槽重量，一鍵填入產銷排產起算日。
3. **共用原料池與負庫存赤字精確遞延**：
   - 一廠 5 槽共用池負庫存赤字遞延繼承機制，赤字按槽均分，次日期初負值以紅字與紅底高亮警示。
   - 支援原料池槽位自由勾選排除或納入，動態重算現存原料集合。
4. **原採進貨智慧解析與跨廠儲槽分配**：
   - 支援採購進貨批號（例如 `CIF-5 2609-I05 175MT`）精確正則解析，自動分離單號、批號與噸數。
   - 跨廠儲槽選單（彰濱一廠共用池/獨立槽、崙尾二廠 TK617/TK618），自由跨廠進料分配。
5. **PWA 獨立 App 與離線快取**：
   - 支援 Service Worker（`ipa-pwa-v3.11`）快取，即便工廠訊號不佳亦可秒速載入。
   - 修正台灣時區 (UTC+8) 時間顯示與 ershine 專屬高解析度 App Icons。

## 操作步驟

### 1. 線上使用
1. 直接使用瀏覽器開啟 [https://ipa-pwa-app.pages.dev](https://ipa-pwa-app.pages.dev)。
2. 可點選瀏覽器網址列之「安裝 App」將系統常駐於桌面。

### 2. 日報匯入與排程試算
1. 點擊畫面頂部 **「📂 匯入日報 Excel」**，選擇當月的儲槽作業日報檔案。
2. 系統彈出分頁清單，點選指定日期之分頁並按下「⚡ 自動填入產銷 12 日起算」。
3. 系統即會自動將各槽 08:00 重量填入，並啟動動態進耗存平衡推演。
4. 完成調整後，點擊右上角 **「💾 儲存至雲端」**，資料將透過 Cloudflare D1 即時同步至所有電腦。
