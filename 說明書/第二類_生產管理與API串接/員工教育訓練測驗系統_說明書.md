# 員工教育訓練測驗系統 (hr_quiz_v2) - 操作說明書

> 🔗 **GitHub 專案庫**：[shihwei0809/google-agent/tree/main/影片生成/hr_quiz_v2](https://github.com/shihwei0809/google-agent/tree/main/影片生成/hr_quiz_v2)

## 專案簡介
本專案為簡報播放與測驗作答合一的員工教育訓練網頁系統。員工可直接在瀏覽器中觀看簡報、聽取語音朗讀，並在簡報播放結束後直接進行測驗。測驗結果會自動寫入 Google 試算表，方便人資與管理人員統計作答紀錄。

## 主要功能特色
- **免安裝**：前端為純 HTML + JS，員工開啟即可作答，不需要安裝任何軟體。
- **簡報播放與語音朗讀**：整合簡報展示，並提供繁體中文語音朗讀功能，支援 0.7x ~ 1.5x 播放速度調整與自動換頁。
- **雲端同步**：透過 Google Apps Script (GAS) 將測驗結果（作答時間、姓名、各題答案）寫入雲端 Google 試算表。
- **免代碼題庫與設定修改**：簡報內容（標題、圖片、朗讀文字）與測驗題目均可直接在 Google 試算表中修改，系統載入時會自動同步最新題庫，無需修改 HTML 程式碼。
- **內網一鍵共享**：內建 Python 與免 Python (Windows 內建) 的內網啟動器腳本，一鍵啟動本地網頁伺服器，讓同一個局域網/Wi-Fi 下的手機或電腦直接連線作答。

## 技術棧
- HTML5, CSS3, JavaScript (Vanilla JS)
- Google Apps Script (GAS)
- PowerShell (Windows 內網伺服器支援)

## 連接 Google Sheet 與部署步驟
1. **建立 Google Sheet**：前往 [sheets.new](https://sheets.new) 建立新試算表，命名為「員工測驗紀錄」。
2. **開啟 Apps Script**：在該試算表上方選單，點選 `擴充功能` -> `Apps Script`。
3. **貼上程式碼**：將專案中的 `apps_script_code.gs` 內容全部複製，貼入 Apps Script 編輯器中取代原代碼並存檔。
4. **新增部署作業**：
   - 點選右上角 `部署` -> `新增部署作業`。
   - 類型選擇：`網頁應用程式`。
   - 執行身分：`我`。
   - 誰可以存取：`所有人`。
   - 點選 `部署`，並複製產生的網頁應用程式 URL（API 網址）。
5. **填入 index.html**：打開 `index.html`，將 `const APPS_SCRIPT_URL = 'YOUR_APPS_SCRIPT_URL_HERE';` 替換為剛才複製的 API 網址，保存即可。

## 本機內網共享作答方式
若要讓同仁在同一個 Wi-Fi/局域網下透過手機或電腦連線至您的本機進行測驗：
- **若本機已安裝 Python**：雙擊執行 `點我啟動內網伺服器.bat`。
- **若本機未安裝 Python**：雙擊執行 `點我啟動內網伺服器(Windows內建無須Python).bat`。
- 啟動後，請勿關閉視窗，同仁只需在瀏覽器中輸入視窗內顯示的逆色網址（例如：`http://192.168.3.35:8000/index.html`）即可直接開始作答。
