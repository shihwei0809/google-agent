## 專案簡介
本專案為工廠槽車回收液進廠入料的專業行動端記錄與查核系統。採用 **Cloudflare Pages + D1 Database + Google Apps Script / Google Drive** 雙軌雲端架構，作業員可持手機或平板在現場進行「入料前（車輛、入料前液位）」與「入料完成（入料後液位）」兩階段拍照與紀錄，並自動統計入料歷時。

---

## 核心功能特色
1. **兩階段入料流程與防呆**：
   - **入料前記錄**：拍照記錄車輛外觀、入料前槽體液位計，並輸入車號、日期。
   - **暫存與接續入料**：入料作業進行中，單據以 `pending` 狀態儲存於 Cloudflare D1 與本機 IndexedDB。
   - **入料完成記錄**：卸料完成後，點選該車輛拍攝「入料後液位」，系統自動計算歷時（分鐘）並封存完成。
2. **高可用雙軌雲端架構 (D1 + GAS)**：
   - **結構化資料**：即時寫入 Cloudflare D1 雲端關聯資料庫（`recycle_records`），提供毫秒級原子事務與跨機同步。
   - **照片歸檔儲存**：照片 Base64 非同步送至 Google Apps Script，自動依 ISO 週別（例如 `2026年第42週`）自動分類存入 Google Drive「回收液照片歸檔」資料夾，零空間阻礙。
3. **PWA 離線優先與 Stale-While-Revalidate 秒開**：
   - 支援離線快取與獨立 App 安裝，現場訊號弱時依然 0 秒瞬間渲染本機暫存卡片，背景非同步平滑對齊雲端。
   - `finally` 確保提交按鈕不卡死，並防護後台刪除之孤兒資料自動清除。
4. **查詢歷史與密碼鎖定**：
   - 內建安全密碼鎖（預設：`7588555`），解鎖後可即時篩選、搜尋歷史入料明細與照片連結。

## 系統版本與技術棧
- **前端架構**：HTML5, CSS3 (深色霓虹科技風), Vanilla JavaScript (ES6+), PWA Service Worker (Network-First)
- **後端 API**：Cloudflare Pages Functions REST API (`/api/records`)
- **資料庫**：Cloudflare D1 (SQLite on Edge)
- **雲端硬碟自動化**：Google Apps Script (GAS) + Google Drive API
- **本機伺服器備援**：Python FastAPI (`run_server.py`)

## 操作步驟

### 1. 線上直接使用 (推薦)
1. 使用手機、平板或電腦開啟 [https://recycle-feed-records.pages.dev](https://recycle-feed-records.pages.dev)。
2. 可點擊瀏覽器網址列或畫面上的「安裝 App」新增至桌面快捷方式。

### 2. 現場操作流程
1. **步驟 1 (入料前)**：點擊「入料前記錄」，依序拍攝車輛正面/車牌與目前儲槽液位計，輸入車號與進場時間，點擊「儲存入料前記錄」。
2. **步驟 2 (卸料中)**：畫面切換至「待入料清單」，顯示目前廠內正在卸料的車輛。
3. **步驟 3 (入料完成)**：卸料完成後，點擊該車輛卡片的「完成入料」，拍攝最終液位計照片並確認，系統自動計算「歷時 X 分鐘」並上傳存檔。
4. **步驟 4 (歷史查驗)**：點選「查詢歷史」，輸入授權密碼即可即時調閱歷史照片與詳細紀錄。
