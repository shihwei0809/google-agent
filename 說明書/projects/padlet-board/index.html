資材課留言板使用說明

📢 系統簡介

本系統是專為資材課同仁開發的雲端協作看板，支援工作交接、異常通報、稽核巡檢、SOP 規範共享及改善追蹤。所有修改皆會即時、異步同步到 Google 雲端資料庫。

🎯 基礎操作教學

  • 新增欄位：點選右上角【新增欄位】或在背景空白處雙擊滑鼠左鍵即可新增一個主題分類。
  • 修改欄位標題：直接點選欄位標題，編輯完畢後點選空白處或按 Enter 即可儲存。
  • 張貼新卡片：點選欄位下方的【張貼在此欄位】或 + 按鈕。您可以填寫姓名、標題與內文，並可選填超連結或圖片網址，系統會自動生成卡片預覽。
  • 編輯與刪除卡片：將滑鼠懸停於卡片上，右上角會顯示編輯 ✏️ 和刪除 🗑️ 按鈕，點選即可操作。

💬 協作與討論

  • 愛心確認 (點讚)：點選卡片左下角的「愛心」圖示，表示「已閱」或「已核對」。
  • 留言討論：點選卡片下方的「訊息氣球」圖示展開留言區，輸入您的留言內容並按 Enter 送出。

📈 簡報、分享與每日看板

  • 每日切換：點擊標題旁日曆可切換日期，若該日期無看板，會自動複製前一次的欄位結構以利快速張貼。
  • 投影片放映：點擊【投影片】進入全螢幕放映模式，可用鍵盤左右方向鍵切換，按 Space 下一張，按 Esc 退出，支援自動播映。
  • 分享看板：點擊【分享】獲取網址連結與即時 QR Code 條碼，便於手機快速掃描開啟協作。

🤖 AI 智慧助理「小鴻」

  • 設定 API Key：打開側邊欄點選 ⚙️ 設定您的 Gemini API 金鑰（儲存在您本機瀏覽器，保護機密不外洩），確認顯示為 🟢 服務就緒 即可。
  • 🎙️ 語音辨識輸入：在卡片內容編輯區或 AI 側邊欄中，點選麥克風圖案即可口說輸入內容或語音提問。
  • ✨ AI 文本處理：卡片內容框上方可選擇【AI 潤飾】（標準三段式報告格式）、【條列化】或【總結摘要】並點擊執行，自動改寫排版。
  • 🧠 一鍵 AI 5-Why 診斷：點選卡片底部的【AI 診斷】按鈕，小鴻會對該卡片事件進行 5-Why 根因分析與預防 CAR 建議，並直接張貼為留言。
  • 💬 智慧上下文對話：點選「AI 助理」可開啟側邊欄對話，小鴻會自動讀取今日看板卡片資訊，解答同仁的品質通報與 ISO 規範問題。

📡 狀態指示燈與疑難排解

  • ☁️ 雲端已同步：所有新增、點讚與留言已成功寫入 Google 雲端資料庫。
  • 🔄 同步中...：資料正在與雲端通訊上傳，請稍候。
  • 🔌 本機模式 / ⚠️ 同步失敗：代表網路斷線或發生 Google 帳號授權衝突。
    💡 解決方案：當您的瀏覽器同時登入多個 Google 帳號時會被 Google 阻擋，請使用瀏覽器的「無痕視窗 (Incognito)」開啟此留言板，即可恢復正常同步！
