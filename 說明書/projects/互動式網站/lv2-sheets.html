1. 關於 Level 2 使用 Google Sheets 作為後端資料庫的限制，以下何者正確？

A. 寫入反應時間約需 1~2 秒，且大班級多人同時寫入時試算表可能發生衝突鎖死
B. 寫入速度極快，能輕鬆處理數千人每秒數十次的即時排行榜連線
C. Google Sheets 無法透過任何外部 API 讀取，只能手動在瀏覽器開啟
D. 試算表寫入完全不需要任何後端代理服務程式
解析：選 A。Google Sheets 的 API 回應較慢（透過 GAS 做轉發代理通常要 1 秒以上），不適合即時同步要求極高的多人遊戲。當多人同時寫入時，必須使用鎖（LockService）限制，這會造成排隊等待，甚至可能超時卡死。
