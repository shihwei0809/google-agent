# 🎬 PDF 語音克隆影片生成器 (pdf-to-video-cloning) — 說明書

本專案在原有的「PDF 語音旁白影片生成器」基礎上，完美對接了本機的 **VoxCPM2 聲音克隆技術**。同仁可以選擇以自己錄製的真實聲音為簡報配音並生成影片。

---

## 🛠️ 功能與技術特點

### 1. 本地克隆音色掃描
* 系統會自動讀取 [**`AI 克隆聲音/voices/`**](../../AI%20克隆聲音/voices) 目錄下所有已錄好的聲音名字（例如 `小偉`），並直接呈現在步驟 3 的配音選單中。

### 2. 免 API 費用與無每日上限
* 推理完全於本機的顯示卡（或 CPU）上運行，完全不消耗 any Gemini API 額度，亦不產生任何額外雲端費用。

### 3. 子程序非同步推理 (Subprocess Call)
* 採用獨立環境子程序進行語音合成，避免套件版本衝突，並自動繼承本機顯卡 CUDA 加速，合成一部簡報影片僅需 1~2 分鐘。

### 4. 語音錄製對接
* 卡片面板中整合了 **「🎙️ 錄製新聲音 (Port 7860)」** 的捷徑，點擊可開啟 Gradio 錄音介面錄製新的參考聲音。

---

## 🚀 操作步驟

1. **啟動伺服器**：
   - 進入 `pdf-to-video-cloning` 目錄下。
   - 雙擊執行 **`啟動語音旁白影片生成器.bat`**。
   - 瀏覽器自動開啟 **[http://localhost:8003](http://localhost:8003)**。
2. **上傳簡報與調整腳本**：上傳 PDF，點擊「讀取 PDF」提取文字並微調。
3. **選擇克隆聲音**：
   - 在步驟 3 切換到 **「VoxCPM2 本地克隆語音」** 頁籤。
   - 在下拉選單中選擇要使用的克隆配音人，並可點選右邊的 `▶` 進行試聽。
4. **合成影片**：
   - 點擊最下方「開始生成影片」，片刻後即可在網頁端直接下載影片成品。
