# 產品製程流程圖系統 (flowchart-web) - 操作說明書

> 🔗 **GitHub 專案庫**：[shihwei0809/google-agent/tree/main/flowchart-web](https://github.com/shihwei0809/google-agent/tree/main/flowchart-web)


## 專案簡介
此專案為鴻勝化學的「產品製程流程圖系統 (槽體製程管控系統)」，提供廠區槽體、原料、製程、成品槽及格外品之互動式流程圖與即時狀態監控。

## 主要功能特色
- **SVG 互動式畫布**：高解析度 SVG 流程圖，可縮放、平移，點擊任一槽體可查看詳細規格。
- **液位動態視覺效果**：槽體詳細資訊彈窗中，液位計具備動態水波動畫與即時數值更新。
- **重要製程數據**：實時顯示溫度、壓力、成分狀態，並支援 N2 吹掃動態模擬。
- **側邊欄智能導航**：快速過濾不同區域的製程槽體。
- **匯入/匯出功能**：支援將配置參數與手動產能備份為 JSON 檔案下載，並可隨時匯入復原。

## 技術棧
- HTML5, CSS3, JavaScript (ES6)
- SVG (可縮放向量圖形)

## 本機執行與操作
1. 進入 `flowchart-web` 目錄，雙擊 `index.html`。
2. 點擊畫面上的槽體（如原料槽、成品槽），將彈出詳細規格視窗。
3. 可點擊上方的 **「修改產能描述」** 手動調整黃色總產能標示，或點選 **「匯出/匯入」** 備份目前配置。
