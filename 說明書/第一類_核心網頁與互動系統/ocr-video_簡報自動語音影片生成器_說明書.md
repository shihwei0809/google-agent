# 簡報自動語音影片生成器 (ocr-video) - 操作說明書

> 🔗 **GitHub 專案庫**：[shihwei0809/google-agent/tree/main/OCR測試](https://github.com/shihwei0809/google-agent/tree/main/OCR測試)

## 專案簡介
本專案為一個高效率的「PDF 簡報自動化語音影片生成系統」，能夠將任何簡報 PDF 檔案，全自動解析為每頁投影片的影像，並透過 OCR 辨識投影片內容，最終結合微軟高音質的台灣女生配音，渲染輸出為高畫質的 MP4 導覽影片。

本專案同時提供了**單機指令版**與**視覺化網頁編輯介面（Web UI）**，方便同仁在直觀的介面上即時修正配音稿、聽取語音預覽並一鍵產生影片。

## 主要功能特色
- **Gemini TTS 支援 (自然情緒配音)**：整合 Gemini 自然情緒語音，支援具備呼吸感、語調起伏與更為自然的旁白語音選項。
- **多金鑰自動輪替 (多 Key 備援)**：在 Step 1 解析簡報或 Step 3 生成語音時，API 金鑰框支援多行輸入（**一組一行**）。當某組免費金鑰達到每分鐘限流 (429) 或每日限制時，後端會自動輪替下一組金鑰繼續解析或生成，避免中斷。
- **舊專案救援與重新合成工具**：在 Step 1 頁面下方內建專案救援面板。若在最後合成階段因故失敗，或想手動重新合成，可直接展開面板，系統會抓取硬碟中已生成好的圖片及音效檔，一鍵重新合成影片（**免重新上傳、不花費任何 API 額度**）。
- **人性化資料夾命名**：專案資料夾與救援清單一律改用 `[PDF簡報名稱]_[時間戳記]` 命名（取代原有的 UUID 亂碼），讓人員在檔案管理上能輕鬆識別專案。
- **1.2x 降載解析度優化**：預設將投影片圖片匯出比例調降至 1.2x，在維持 EasyOCR 高精準度的前提下，將 CPU 辨識文字的速度提升 4 到 5 倍。
- **純原生音訊處理與 FFMPEG/MoviePy 合併**：在背景以最優化設定將影像與語音音軌快速無損合併，完全避免了傳統音訊多處理器鎖定（Deadlock）的崩潰問題。
- **視覺化 Web 編輯平台**：
  - 採用深色質感玻璃微光風格（Glassmorphism）UI。
  - 提供**圖文對照編輯**，左側為投影片縮圖，右側為可編輯旁白輸入框，方便直接刪除頁碼等雜訊。
  - 內建 **「▶ (試聽)」** 按鈕，可在瀏覽器中直接試聽個別投影片的發音效果，試聽時不影響目前已選定的語音設定。
  - 支援網頁端直接播放生成影片與一鍵下載成品。

## 技術棧
- **後端服務**：FastAPI (Python 3.12), Uvicorn
- **文件解析**：PyMuPDF (fitz)
- **文字辨識**：EasyOCR (PyTorch)
- **語音合成**：edge-tts (Microsoft Cognitive Services, 預設 `zh-TW-HsiaoChenNeural` 台灣女聲)
- **多媒體處理**：moviepy, FFmpeg (影像影像串接與音軌疊加)
- **前端介面**：HTML5, CSS3 (Vanilla), JavaScript (ES6)

## 🚀 視覺化網頁操作步驟 (推薦)

### 第一步：啟動本機網頁伺服器
1. 進入 `pdf-to-video` 目錄下。
2. 雙擊執行 **`啟動語音旁白影片生成器.bat`** 批次檔（已修復為直接呼叫系統內建 `python`，可移植於各電腦）。
3. 系統將會啟動本地後端服務（監聽 Port 8002），並自動在您的瀏覽器中開啟 **[http://localhost:8002/](http://localhost:8002/)** 編輯頁面。

### 第二步：上傳 PDF 並提取旁白
1. 將簡報 PDF 檔案拖曳至網頁的拖放區域中，或點擊上傳。
2. 選擇**解析模式**。若選擇 `Google Gemini` 智慧模式，可在 API 金鑰框中貼上您的金鑰（**支援多組，每行輸入一組**，遇到 429 限流時系統會自動換下一行 Key 繼續解析）。
3. 點擊 **「讀取 PDF」** 按鈕。網頁會顯示進度條，完成後會自動展開「旁白編輯列表」。

### 第三步：編輯旁白與試聽語音
1. 在各投影片旁的輸入框中直接修改文字。建議刪除頁碼與投影片中的排版贅字。
2. 點擊「選擇語音」前進到 Step 3：
   - **Edge TTS**：免費且無限次數，提供多種中英文發音人，並可調整語速。
   - **Gemini TTS**：能產生語調極為自然的擬真語音。此處需要配置 API 金鑰（**支援多組，每行一組，因免費版每日上限為 10 次，強烈建議輸入 4 組合以上**）。
3. 點擊卡片右側的 **「▶ (試聽)」**，可在實際合成前先聽取一小段音訊，且試聽不會影響已選中的語音角色。

### 第四步：合成並下載影片
1. 確認所有頁面的旁白文字皆正確後，點擊最底部的 **「開始合成並產生導覽影片」** 按鈕。
2. 系統在合成語音時，若遇上 Gemini 限制會自動切換下一組 Key。
3. 生成完畢後，網頁將會切換至成品頁面。您可以在線上直接觀看，並點選下載 MP4 影片。

## 🛠️ 專案救援與重新合成操作

若您的簡報頁數較多（例如 30 頁以上），且在最後一步「合成影片」因故中斷，或是想針對歷史專案進行重新合成：
1. 開啟首頁，直接滑到最下方，點選 **「🛠️ 舊專案救援與重新合成工具 (展開)」**。
2. 點擊 **「🔄 重新整理專案列表」**。系統會偵測到您在 `jobs` 中所有已產生的圖片與語音檔。
3. 尋找您對應的專案名稱（以簡報檔名命名，例如 `工作規則簡報_20260714_190000`）。
4. 點擊右側的 **「🎬 立即合成影片」**。
5. 網頁會跳轉至 Step 4 直接將您硬碟中已產生好的圖片與音訊拼裝合成（**僅需約 1~2 分鐘即可完成，完全免除前面一小時的等待，也不會消耗任何 API 額度**）。

## ⌨️ 終端機指令操作步驟 (工程師專用)

若您習慣使用指令進行操作，可以透過以下方式執行：

* **一鍵直接生成影片（預設全部流程）**：
  ```bash
  python pdf_onekey_video.py --pdf "您的簡報.pdf"
  ```

* **第一階段（僅生成文字草稿並停止）**：
  ```bash
  python pdf_onekey_video.py --pdf "您的簡報.pdf" --prepare
  ```
  *此時您可以手動打開 `video_output/narration.json` 修正各頁面的文字。*

* **第二階段（載入編輯後的說明稿合成影片）**：
  ```bash
  python pdf_onekey_video.py --pdf "您的簡報.pdf" --generate
  ```

## ⚠️ 避坑與維護注意事項
1. **中文字元路徑編碼限制**：OpenCV 在 Windows 下若遇到包含中文的檔案路徑，常會因為編碼解析出錯而無法開啟圖片。本專案已改用 `PIL (Pillow)` 讀取圖片，並轉換為 `NumPy` 陣列直接傳遞給 EasyOCR 處理，請勿改回直接傳遞路徑字串。
2. **多進程死鎖防範**：簡報投影片頁數較多時，請勿在迴圈中建立多個 `AudioFileClip` 子進程讀取個別音檔，否則會佔用大量本機系統管線（Pipes）導致程式卡死。本專案一律先輸出 MP3，以 `ffmpeg concat` 合併為單一音檔後，再使用單一 `AudioFileClip` 進程載入合成。
