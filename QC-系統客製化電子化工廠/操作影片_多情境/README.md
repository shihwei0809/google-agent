# QC 多情境操作影片

影片依本機 PWA 專案畫面與目前部署頁（2026/10/03 可見之排程快速篩選）編排，示範資料皆為合成資料。正式版可能因系統更新、權限與設定而略有差異。影片沒有連線正式雲端 API，也沒有實際送出 Teams 訊息。

## 影片

- `03_QC不合格退回與重送.mp4`：FAIL 判定、退回原因及下一輪送樣紀錄
