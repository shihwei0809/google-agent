# 🌐 台積電槽車 Barcode 三合一單網頁架機伺服器

## 專案簡介
本系統為**免安裝 Python 環境的區域網路架機服務**。現場只需一台主機執行 Python 後端，同區域網路內的所有作業人員即可使用瀏覽器（Chrome/Edge）進行排程批號貼上、Excel 匯入或上傳 COA 檢驗截圖，由架機主機即時產生符合台積電規範的三合一單 Excel（含動態 QR Code 與 COA 單列精確裁切）與標準排版運輸通知表。

---

## 核心功能亮點
- 🚀 **區網免安裝免設定**：同仁手機/平板/電腦直接開啟網頁（http://[主機IP]:8002）即可操作。
- 📊 **Excel 智慧匯入與多分頁支援**：直接解析 Excel 檔案內所有分頁，支援「📅 優先抓今天~後天」排程快速篩選。
- 🖼️ **COA 影像 AI 智慧裁切 (Tesseract.js + Pillow)**：
  - 瀏覽器端純前端 OCR，無需於主機安裝 .exe 執行檔。
  - 自動精確定位各筆批號座標，將三合一單 F5 截圖裁切為【上方單行表頭 + 該筆專屬批號數據列】，其餘批號列自動去除。
  - 嵌入 Excel 時自動設定標準尺寸：**寬 23.7 公分 (~896px) × 高 11.5 公分 (~435px)**。
- 📑 **運輸通知表雙色排版與既有通知表修訂**：
  - 全面移植 openpyxl 排版引擎（黃底標題、綠底日期、鮮黃底槽號、紅字廠區）。
  - **支援一鍵載入既有 `運輸通知表.xlsx`**：自動依 7 列卡片循環還原所有排程，直接填寫【修正到廠時間】即可重新生成右側併排「出貨排程修正通知」卡片。
- 🔀 **Port 佔用自動切換與 IP 廣播 (Rule 6)**：預設 8002 被佔用時自動順延，啟動時自動輸出本機區域網路 IP。

## 跨電腦一鍵啟動與執行步驟

### 1. 啟動伺服器 (架機人員)
雙擊執行 架設伺服器_一鍵啟動.bat。
系統會自動檢查並安裝缺少的套件，隨後開啟主控台並顯示：
`	ext
============================================================
TSMC Lorry Barcode Server started successfully!
Local URL: http://localhost:8002
LAN URL: http://192.168.x.x:8002
============================================================
`

### 2. 開啟與操作 (作業同仁)
同仁在瀏覽器輸入 http://[主機IP]:8002：
1. **輸入排程**：直接複製 Excel 表格貼上，或點擊「📥 從 Excel 匯入」篩選今天至後天出貨資料。
2. **COA 裁切 (選用)**：點擊「🖼️ 上傳 COA 截圖」，系統自動定位各批號座標。
3. **下載報表**：點擊「🚀 一鍵產生所有報表 (ZIP)」下載包含三合一單與運輸通知表之 ZIP 檔。
