# 化學品防爆倉儲專案 (Chemical Explosion-Proof Pallet Shuttle Warehouse)

## 專案簡介
本專案為「1,000 m² 化學品防爆棧板穿梭車（Pallet Shuttle）倉儲規劃與可行性評估」，旨在建立高密度、自動化且符合最高安全標準的危險化學品倉儲系統。

## 核心功能亮點
- **防爆自動化**：全場採用防爆等級 (EX) 的棧板穿梭車 (Pallet Shuttle)。
- **高密度儲存**：相較於傳統貨架，空間利用率提升 60% 以上。
- **智能溫控與環安衛 (EHS)**：整合 WMS/WCS 與氣體偵測、溫溼度監控及消防連動系統。

## 檔案結構說明
- `README.md`: 專案首頁與導覽說明。
- `SKILL.md`: 給 AI 助理閱讀的技能與環境配置說明。
- `setup_env.ps1`: 環境與依賴套件一鍵安裝腳本。
- `1000m2_Chemical_Pallet_Shuttle_Feasibility_Report.md`: 核心可行性評估報告書。

## 跨電腦一鍵啟動與執行步驟
1. 取得專案後，請先執行 `setup_env.ps1` 確保環境依賴安裝完成。
2. 參考報告書內容進行各項細部工程評估。
