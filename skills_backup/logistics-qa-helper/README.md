# ISO 槽車與條碼驗證專案 (logistics-qa-helper)

本專案升級自 `isotank與條碼` Gem，專門協助處理 ISOTANK 卸料排程、流速計算與原物料條碼 (Regex) 零誤差驗證。

**固定的是流程＋規格（凍在 Skill / 本檔 / scripts），浮動的是材料（每次丟 `input/`）。**

## 固定偏好（每次套用）
- 回應一律用繁體中文。
- 對於卸貨流速、載重等物理數據與預估時間，以及條碼驗證結果，必須保持絕對精確，禁止任何通融與猜測。
- **計算與正則驗證全部交給 Python 運算執行，模型只負責解讀與包裝輸出，確保零幻覺**。

## 怎麼用
1. 將物流數據或待核對的條碼字串寫入 `input/materials.txt`（例如：載重 `18T`，流速 `1.2T/hr`，待測條碼 `N260530A-001`）。
2. 執行對應的計算工作流：
   - `/isotank-calc` : 計算預估卸貨時間與完成時程。
   - `/barcode-verify` : 驗證條碼是否符合 TSMC N-series 標準 Regex 規則。
3. 到 `output/` 取回您的計算分析與認證報告。
