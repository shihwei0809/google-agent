# 小包系統報表產生 (勝一專用版)

專為勝一廠區操作流程客製化之生產履歷與 COA 報表自動化產生系統，具備智慧排程解析（支援「電子課出貨排程」桶裝 Excel）、地點自動對照、QR Code 標籤生成與 Excel 報表自動匯出功能。

---

## 核心功能亮點

- **勝一專案獨立運作**：與鴻勝版本完全隔離，專屬邏輯與報表格式修改互不干擾。
- **認列不認批號**：匯入排程時無論同批號或不同日期/PO，逐列獨立建單，產出檔案自動加上 `(1)`、`(2)` 後綴防止覆蓋。
- **地點智慧正規化**：支援人員輸入或排程含有各式寫法（如 `18廠p2`、`18p2`、`15廠p5`），自動精準正規化並自動帶出長代號與料號。
- **Excel / CSV 智慧匯入**：具備全列掃描與標題模糊比對防呆機制，即使排程欄位順序更動或標題缺漏，亦能精確提取地點與批號。
- **生產履歷與 COA 雙重自動生成**：一鍵產生客戶端專用 COA 報告與 Chemical_Lorry 生產履歷活頁簿。
- **免裝 Git 雲端一鍵自動更新**：內建雙模式更新精靈，現場同仁無 Git 環境亦可直接自 GitHub 下載最新版程式。

## 快速啟動與執行步驟

### 第一次使用（環境初始化）：
1. 雙擊執行 `setup_env.ps1`，或直接雙擊 `啟動本機視窗版.bat`。
2. 腳本會自動檢查 Python 3.9+，並自動補齊缺少套件（`openpyxl`、`Pillow`、`qrcode`、`pytesseract`）。

### 平時日常使用：
- 雙擊 **`啟動本機視窗版.bat`** 即可立即開啟操作視窗。

### 軟體更新：
- 雙擊 **`一鍵更新系統程式.bat`**，系統將自動從雲端獲取最新版 `main.py` 並自動重新啟動。
