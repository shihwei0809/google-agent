# AI 面試語音特質與資材適性分析系統 (interview_analyzer)

## 專案簡介
本專案為針對 HR 人資與資材主管設計的 AI 履歷預評與語音特質分析系統，具備以下核心能力：
1. **事前履歷預先分析與擬定提問 (Pre-interview Analysis)**：支援上傳 PDF/圖片/文字履歷，自動產出契合度分析、歷練與通勤疑點，並擬定 4~6 個結構化面試提問題目與 Word 報告。
2. **長面試背景自動備份 (Chunked Auto-Save)**：預設每 5 分鐘背景分段備份，防止斷電失誤與面試結束等待。
3. **資材部黃金 DISC 比對**：針對現場助理工程師、資材工程師與資材行政自動做 CS/SC 型特質評估。
4. **多 Key 自動輪替與 Cascade 降階**：支援貼入多組 Gemini API Key，自動切換 Gemini 3.6-flash -> 3.5-flash。
5. **一鍵導出 Word (.docx) 評估報告**：內含事前履歷提問報告與現場語音特質報告。

## 執行與安裝方法
- **一鍵啟動**：雙擊執行 `雙擊點我啟動面試語音AI分析系統.bat` 或在 Powershell 執行 `./setup_env.ps1`。
- **網址**：`http://localhost:8000`
