# 🎓 員工教育訓練測驗產生系統 — SOP 操作說明書

本系統是一款**純前端、零安裝、免伺服器**的智慧型 SOP 教育訓練與測驗封裝工具。系統能透過 AI (Google Gemini 或 Groq Llama) 自動分析您的文字或教材檔案，一鍵生成具備**圖文並茂投影片、語音合成配音 (TTS)、防刷鎖定、測驗挑戰**以及**本機/雲端成績回收**的完整訓練網頁包。

---

## 📁 系統目錄結構
解壓縮產生的檔案包後，結構如下：
```text
儲槽進出貨作業培訓_教育訓練測驗套件/
├── index.html                           # 主播放與測驗網頁（同仁開啟此檔受訓）
├── serve_intranet.txt                   # 內網本機伺服器程式（以安全 .txt 格式儲存）
├── 點我啟動內網伺服器(Windows免安裝).bat   # 一鍵啟動內網伺服器的批次檔
├── apps_script_code.gs                  # Google Sheets 雲端同步成績腳本
└── README.md                            # 基礎部署說明文件
```

## 🚀 步驟一：教材匯入與 AI 參數設定

1. **開啟產生器**：
   - 雙擊開啟 `sop_generator/index.html`。
2. **設定 API 金鑰**：
   - **AI API 提供商**：可選擇 `Google Gemini (AI Studio)` 或 `Groq (Llama / Mixtral)`。
   - **API 金鑰**：貼上您的 API Key（Groq 模式下已內建預設金鑰，若過期可自行申請替換）。
   - **選擇模型**：建議使用預設推薦的 **`Gemini 3.5 Flash`** 或 **`Llama 3.3 70B`**，速度最快且精準度最高。
3. **設定引數**：
   - **簡報投影片頁數**（5 ~ 15 頁）與**測驗題目數量**（3 ~ 10 題）。
   - **及格分數**（60 ~ 100 分）。
   - **啟用防刷限制**：勾選後，受訓同仁必須「聽完該頁的所有語音配音」，下一頁按鈕與測驗挑戰才會解鎖，防止同仁直接快速跳過。
4. **匯入 SOP 素材**（支援三種方式）：
   - **直接貼上**：將文字貼入右側大文字框。
   - **拖放/點擊上傳檔案**：支援 `.txt`、`.md`、`.pdf`、`.docx`、`.pptx`，系統會自動在瀏覽器本機解析並提取文字。
5. **開始分析**：
   - 點擊「✨ 開始自動分析與產生簡報測驗」，稍候約 10 ~ 15 秒即可完成。

---

## ✍️ 步驟二：線上審查與內容微調

AI 產生完畢後，會直接進入第二步編輯畫面。您可以對內容進行最終確認或手動修改：

### 1. 簡報投影片編輯
- **投影片標題** 與 **條列重點 (Bullets)**。
- **語音朗讀配音文字 (Narration)**：此處文字將在播放時透過合成語音讀出。可點選「🔊 試聽此頁配音」預覽發音效果。
- **代表圖示 (Emoji)**：設定顯示在投影片左上角的裝飾表情符號。
- **插圖搜尋關鍵字 (imageKeyword)**：設定投影片右欄的插圖。

> 💡 **後續同仁如何自訂自己的圖片（如現場照片或截圖）？**
>
> 預設情況下，只要在「插圖搜尋關鍵字」中輸入英文單字（如 `factory` 或 `safety`），播放器會自動載入雲端圖片庫（LoremFlickr）的對應精美圖片。
>
> 若要替換成**您自己的本機圖片**：
> 1. 將您的圖片檔案（例如 `step1.jpg`、`warning.png`）複製放到與播放器 `index.html` **同一個資料夾**中。
> 2. 在產生器的「插圖搜尋關鍵字」輸入框中，**直接填入該圖片的檔名**（例如：`step1.jpg` 或 `./step1.jpg`）。
> 3. 系統會自動辨識檔名格式，在播放時直接載入該張本機圖片，免去任何程式碼修改！

### 2. 測驗挑戰題目編輯
- 可點擊分頁切換至「📝 測驗挑戰題目」。
- 修改題幹、選項（A, B, C, D）、正確答案與解析。

---

## 📦 步驟三：打包匯出與部署

編輯確認無誤後，點擊右下角「💾 產生並匯出教育訓練套件」，系統將自動下載一個壓縮檔 `[SOP標題]_教育訓練測驗套件.zip`。

### 方式 A：單機使用（同仁在自己的電腦上開啟）
- 將 ZIP 壓縮檔解壓縮。
- 雙擊開啟 `index.html` 即可開始上課與測驗。
- *備註：單機開啟時，同仁做完的成績只會保存在他自己的瀏覽器本機紀錄中。*

### 方式 B：內網連線模式（最推薦，免設定自動回收成績）
若您想回收所有同仁的受受訓成績：
1. **解壓縮**：將 ZIP 壓縮檔解壓縮至您的 Windows 電腦。
2. **啟動內網伺服器**：
   - 雙擊執行 **`點我啟動內網伺服器(Windows免安裝).bat`**。
   - 系統會彈出一個黑色的命令行視窗，並以綠色字體印出您的內網 IP 連線網址（例如：`http://192.168.1.100:8000/index.html`）。**請保持此視窗開啟，不要關閉**。
   - *安全提示：本伺服器程式特別將執行腳本重新包裝為純文字的 `serve_intranet.txt`，並透過安全通道加載，完全免除 Windows SmartScreen 的安全性攔截與警告。*
3. **分發網址**：
   - 將該綠色網址傳送給受訓同仁（手機或電腦皆可）。
   - **前提條件**：同仁的設備必須與您的電腦連線在**同一個辦公室 Wi-Fi 或公司內部網路**下。
4. **回收成績**：
   - 同仁測驗及格並點擊「送出成績」後，您的伺服器資料夾下會**自動產生 `results.csv`**。
   - 直接用 Excel 開啟 `results.csv`，即可看到所有同仁的**姓名、員工編號、分數、受訓花費時間、答題狀況與受訓時間**！

### 方式 C：雲端 Google Sheets 模式
如果您希望將成績即時同步至雲端試算表：
1. 建立一個全新的 [Google 試算表](https://sheets.new)。
2. 點選「擴充功能」->「Apps Script」。
3. 複製套件包中的 `apps_script_code.gs` 程式碼並貼上儲存。
4. 點選右上角「部署」->「新增部署作業」，選取類型為「網頁應用程式」，執行身分選擇「我」，誰可以存取選擇「所有人(Anyone)」，完成授權後複製產生的 **網頁應用程式 URL**。
5. 開啟您的播放器 `index.html`，點選右上角 **⚙️ 系統設定**（密碼預設為 `admin888`），將該網址貼入「雲端同步網址」儲存即可。
