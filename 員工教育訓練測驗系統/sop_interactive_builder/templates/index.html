操作說明 & 問題排除
基本操作流程
  1. 選擇解析模式：本機傳統（免 Key，快速）或 Google Gemini（AI 分析，含考題）
  2. 若選 Gemini，填入 API 金鑰並選擇 AI 模型
  3. 拖曳 PDF 或 DOCX 到上傳區，或點擊選取檔案
  4. 等待分析完成後進入編輯畫面，可修改腳本與考題
  5. 確認無誤後匯出 PPTX 簡報或互動網頁
常見問題排除
❌ 分析失敗：404 Client Error / Not Found
→ API 金鑰無效，或所選 AI 模型不支援此 Key 的方案。
解法：換一組有效金鑰，或改選較舊的模型（2.0 Flash）。系統會自動往下一個模型重試。
❌ 分析失敗：429 Too Many Requests
→ API Key 已達用量限制（Free tier 每日 20 次）。
解法：換一組 Key，或在金鑰欄輸入多組（每行一組）讓系統自動輪替。
⚠️ 分析完成但腳本內容空白
→ PDF 可能是掃描圖片型（非文字 PDF）。
解法：切換到「本機傳統文字擷取」，或先用 OCR 工具將 PDF 轉為可選取文字版本後再上傳。
⚠️ 拖曳沒反應 / 無法上傳
→ 請確認瀏覽器為 Chrome 或 Edge 最新版本。Safari 部分版本的拖曳行為不穩定。
解法：改用點擊方式選取檔案。
ℹ️ 沒有 Gemini API Key 怎麼辦？
→ 選擇「本機傳統文字擷取」即可免 Key 使用，速度最快，但不會自動產生測驗題目。
申請 Key：前往 Google AI Studio 免費申請。
ℹ️ 分析結果錯誤想重新來過
→ 點選右側「歷史專案」載入舊資料，或直接重新上傳同一份檔案。分析失敗時點「點擊以相同檔案重試」不需要重選檔案。
如仍有問題，請聯繫系統管理員並提供終端機的錯誤訊息。
