# N 系小包報表輸出系統操作影片

依據 2026-10-07 的 main.py 版本更新：匯入預覽包含跨分頁、出貨日期區間查詢、起始日單獨查單日、兩個日曆按鈕、筆數選擇、逐列勾選、出貨日／到貨日並列；剩餘天數由 Excel 欄位匯入。影片已加入繁體中文女聲旁白與操作字幕。畫面由程式重製，使用合成批號、品名與範例檔案，非正式環境螢幕錄影；未讀取或修改正式出貨資料，也未產生實際報表。

- `N系報表輸出系統_多情境操作影片.mp4`：四段合輯
- `01_排程匯入與核對.mp4`：日期區間、結束日留白查單日、日曆按鈕、筆數篩選與逐列選取；出貨日／到貨日分開檢查
- `02_載入生產履歷與COA.mp4`：履歷及 COA 範本載入、批號比對、雙日期確認
- `03_批次產生與輸出檢查.mp4`：剩餘天數來源核對、輸出模式、批次產生及結果確認
- `04_常見狀況處理.mp4`：地點對照、批號比對、來源欄位及日期修正

影片右側逐步顯示操作提示；旁白為 Windows 內建繁體中文（台灣）女聲。所有說明字幕已燒錄在畫面中。
