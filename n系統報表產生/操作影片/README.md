# N 系小包報表輸出系統操作影片

影片根據專案 main.py 現行桌面版控制項重製畫面，並使用合成批號、品名與範例檔案。這是字幕式介面教學動畫，非正式環境螢幕錄影；未讀取或修改正式出貨資料，也未產生實際報表。

- `N系報表輸出系統_多情境操作影片.mp4`：四段合輯
- `01_排程匯入與核對.mp4`：排程檔案選取、日期篩選、匯入確認
- `02_載入生產履歷與COA.mp4`：履歷及 COA 範本載入、批號比對
- `03_批次產生與輸出檢查.mp4`：輸出模式、批次產生、檢查結果
- `04_常見狀況處理.mp4`：對照表、批號比對、檔案占用排除

影片右側逐步顯示操作提示，無旁白；所有說明字幕已燒錄在畫面中。
