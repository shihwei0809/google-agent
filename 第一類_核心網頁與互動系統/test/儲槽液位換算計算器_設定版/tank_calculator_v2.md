## 1. 雙向聯動 ⇄ 三向智慧互換功能

本版計算器完整繼承了原版 `儲槽換算計算器.html` 的全聯動互換核心。在「單槽雙向互換」面板中，人員可以任選其中一個欄位輸入，其餘兩個欄位均會自動雙向即時求值：

*   **【方法 A】輸入液位 (mm / % / m)**：正向計算出總容量（L）與總重量（kg）。
*   **【方法 B】輸入重量 (kg)**：逆向推算回總容量（L），並精確計算出對應的毫米液位。
*   **【方法 C】輸入容量 (L)**：同步推算出對應的毫米液位與總重量（kg）。

> [!TIP]
> **多型態自訂算式逆推技術 (Bisection Solver)**
> 
> *   對於常規的線性槽體，逆向計算極為簡單。但對於如崙尾廠區 `TK-605` 這種採用複雜分段二次/三次函數（球形封頭）的儲槽，傳統代數解極難直接實現。
> *   本網頁內部採用了高效的**二分搜尋數值解算器 (Bisection Solver)**，不論使用者在設定頁面中輸入多麼複雜的自訂 JavaScript 算式，系統均能在 0.001 秒內精確逆推回正確的液位，保證三向互換功能對全廠 95 個儲槽完全通用。

## 2. 全新「免改程式」設定面板與防錯指引

我們在網頁工具中新增了第三個分頁 **「儲槽參數設定」**，並在此版本中加入了完整的防錯機制，**現場同仁完全不需要撰寫任何 Excel 算式**：

1.  **內建公式引導說明卡 (Setup Guide Card)**：
    *   在設定分頁最上方直接列出清晰的對照表，說明常規直立槽、固定比重槽、崙尾百分比槽以及特殊球形罐的常數與填寫變數。
2.  **動態編輯視窗引導 (Dynamic Modal Guidance)**：
    *   **動態欄位顯示**：當同仁下拉選擇不同的「公式類型」時，彈窗只會顯示與該公式相關的輸入框。例如選擇「球形封頭式」時，常數係數輸入框會自動隱藏，從源頭避免誤填。
    *   **黃色警示提示字 (Modal Tip Box)**：選擇不同公式時，彈窗內會即時跳出黃色警示說明（例如：*「💡 密度對照式：適用於大多數一般直立儲槽。您只需填入底面積常數與選擇品名。系統會自動在計算時抓取槽溫並LOOKUP對照比重。」*）。
3.  **防錯數據驗證 (Data Validation)**：
    *   **非數字防呆**：若同仁在底面積常數中輸入了字母或中文，系統會彈出警告 `請輸入有效的底面積數字！` 並拒絕存檔，防止前端公式因非數字崩潰。
4.  **資料備份、匯入與同步 (Backup & Sync)**：
    *   **匯出/匯入設定檔 (.json)**：設定完成後，可一鍵將所有的儲槽清單、常數與密度表下載為一個小巧的 JSON 備份檔，並可於同仁手機端一鍵匯入同步。
