# 純語音合成工具 (Pure TTS Generator)

本專案是一個獨立的網頁端語音合成工具，旨在幫助工作人員快速輸入文字，利用 **Edge TTS** 或 **Gemini TTS** 產生高品質的語音檔案。當主簡報影片生成器中的語音 API 發生跳字、漏唸時，可在此單獨生成後下載並手動覆蓋有問題的音訊檔。

## 🌟 核心亮點
1. **多引擎支援**：整合免費的 Edge TTS 與超高品質的 Google Gemini 3.1/2.5 TTS。
2. **多金鑰與備援機制**：Gemini TTS 支援多組 API Key 自動輪詢，並在 Quota 用盡時自動切換模型（如 3.1 Flash）。
3. **語速微調**：支援 `0.5x` 到 `2.0x` 語速微調（預設推薦 `0.9x` / `1.0x`）。
4. **生成歷史與下載**：本機持久化保存生成紀錄，可隨時在瀏覽器上重聽、點選下載覆蓋。
5. **啟動防呆防衝突**：啟動時自動掃描本機實體 IP，若預設 Port `8004` 被佔用，將會自動切換至可用 Port。

## ⚡ 一鍵啟動
1. 第一次執行請先執行 `setup_env.ps1` 初始化環境。
2. 雙擊 `啟動語音合成工具.bat` 即可一鍵運行。
