# Pure TTS Speech Synthesis Tool (純語音合成工具)
- **Name**: pure-tts
- **Environment**: Python 3.10+, fastapi, uvicorn, edge-tts, google-generativeai
- **Command**: `python app.py` (Default Port: 8004)

## Features
- Pure text-to-speech engine using Edge TTS and Google Gemini TTS
- Grouped voice selection, speed rate controls, and multi-key rotation
- Generation history panel with local file downloads and direct playbacks
