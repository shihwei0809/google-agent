# 🎬 PDF 語音旁白影片生成器

這是一套專為簡報設計的 **全自動語音旁白影片生成系統**。上傳簡報 PDF 後，系統會自動辨識/生成各頁腳本，並合成高品質的配音旁白影片（MP4）。

---

## 🚀 快速啟動與區網連線

1. **啟動服務**：直接雙擊目錄中的 `啟動語音旁白影片生成器.bat`。
2. **存取連結**：
   * **本機使用**：瀏覽器開啟 `http://localhost:8002`
   * **區網連線（多人使用）**：伺服器綁定於 `0.0.0.0`，同辦公室人員可在瀏覽器輸入您電腦的區網 IP（例如 `http://192.168.3.35:8002`）直接連線使用，**支援多台電腦同時連線作業**。

---

## 🌟 核心特色功能

### 1. 🤖 智慧簡報腳本解析（支援多模態 AI）
在上傳 PDF 時，您可以自由選擇以下解析模式：
* **Google Gemini (強烈推薦)**：支援 **Gemini 3.5 Flash (預設)**, `Gemini 3.5 Pro`, `Gemini 1.5 Pro` 等多模態模型。將圖片傳給 AI 理解，**自動重新撰寫語氣自然流暢、無贅詞的台灣配音旁白稿**（需填寫 Google AI Studio API Key）。
* **xAI Grok**：支援 `Grok 2 Vision` 影像理解。
* **本地 OCR 影像辨識 (EasyOCR)**：當沒有 API 金鑰或無網路時，自動以本地圖像辨識提取圖片中的文字。
* **本機傳統文字擷取**：直接抓取 PDF 數位字型檔，速度最快（小於 1 秒）。

### 2. 🎚️ 語速控制與「換行自動停頓」設定
在「步驟 3：選擇語音」中，您可以進行以下微調：
* **語速調整 (Speech Rate)**：範圍為 `-30%` 至 `+20%`。**預設推薦為 `-10%`**，這是最適合聽眾邊看簡報邊聽說明的自然語速。
* **自動在換行處加上停頓**：開啟後，系統會自動在沒有標點符號的換行處補上句號（`。`），強制語音引擎在列點之間**自然停頓約 1 秒鐘**（如同真人簡報呼吸與換氣），聽眾理解效果更佳。

### 3. 📥 腳本「匯出與匯入 (.txt)」功能
在「步驟 2：編輯腳本」上方，設有文字檔傳輸按鈕：
* **匯出腳本文字 (.txt)**：將當前辨識出的腳本下載為文字檔，格式極其簡單（以 `=== 第 X 頁 ===` 分隔），可使用 Windows 記事本（Notepad）進行大量編輯。
* **匯入已修改腳本 (.txt)**：在本地修改完成後，一鍵上傳覆蓋網頁輸入框，省去在線上逐頁編輯的時間。

### 4. ⚡ 50 倍極速影片編碼優化
正式版影片合成已全面優化：
* 改用 **`fps=5`（每秒 5 幀，簡報展示完全足夠）**。
* 開啟 **`preset="ultrafast"` 與 `threads=4`** 硬體並行加速。
* 31 頁的長簡報影片合成時間由原本的近半小時**大幅縮短至 1~2 分鐘內**。

## 💡 團隊高效率協作秘訣 (省時、省錢、免 API 費用)

當您與人員已經有了編輯好的旁白腳本（已匯出 `.txt` 檔案）時，後續若想更換發音人、修改某行字或調整語速，**完全不需要重新進行慢速且需要 API Key 的 Gemini/OCR 辨識**：

1. **上傳 PDF**，解析模式勾選 **「本機傳統文字擷取」**（在一秒內快速抓圖，完全免費）。
2. **步驟 2** 點選 **「匯入已修改腳本 (.txt)」**，上傳您存好的腳本。
3. **步驟 3** 選擇新語音/語速，點擊 **「開始生成影片」**。
*這套流程能在 5 秒內完成設定並開始合成，請多多推廣給操作人員！*
