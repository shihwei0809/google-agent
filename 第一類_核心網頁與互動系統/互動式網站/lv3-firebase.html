Lv.3 Firebase 即時競賽架構

利用 NoSQL 即時資料庫（Firebase Firestore）進行秒級同步，投射大螢幕讓全班競賽互動。

⚡ Firebase Firestore 即時監聽與寫入核心程式碼

Firebase 提供 onSnapshot() 監聽器，只要資料庫發生變動，前端網頁會「秒級」自動重新渲染。

// 寫入成績到 Firebase Firestore await db.collection("quiz_results").add({ nickname: studentName, score: finalScore, timestamp: firebase.firestore.FieldValue.serverTimestamp() }); // 排行榜即時監聽與自動重新渲染 db.collection("quiz_results") .orderBy("score", "desc") .limit(10) .onSnapshot((snapshot) => { // 當有新數據寫入時，此 callback 會立刻觸發，更新 UI 排行榜 updateLeaderboardUI(snapshot.docs); });
