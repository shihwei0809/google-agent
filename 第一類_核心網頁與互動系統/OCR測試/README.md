# 📊 AI 圖片 / PDF 雙重 OCR 智慧判讀轉 Excel 系統

本專案提供**「Google Gemini 雲端高精準度」+「本機 EasyOCR 離線雙語」**的雙重光學字元辨識與二維表格自動重構系統。
支援人員使用**手機拍照照片**、**文件截圖**或**多頁 PDF 文件**進行辨識，自動重構為商業級 Excel 活頁簿（.xlsx），並支援線上互動式預覽與一鍵下載。

---

## 🌟 核心功能亮點

- 🤖 **雙重 OCR 智慧切換架構 (線上優先・離線備援)**：
  - **Google Gemini 雲端多模態 OCR（優先）**：當系統具備 Google API Key 時優先調用 Gemini 2.5 進行最高精準度判讀，對模糊字跡、傾斜表格、中文專有名詞與手寫標註具備頂級解析力。
  - **本機 EasyOCR 離線雙語引擎（自動備援）**：無網路、無金鑰或 API 連線繁忙時，系統**自動平滑降級至本機模型**，兼顧隱私與穩定性。
- 📸 **照片專屬優化 (手機相片無損相容)**：
  - **EXIF 自動轉正**：自動讀取相機陀螺儀方向標籤（`ImageOps.exif_transpose`），徹底解決手機直拍上傳後橫躺、倒置導致辨識錯亂的問題。
  - **智慧解析度適配**：自動優化過大之相機原始檔，兼顧文字清晰度與運算速度。
- 📑 **多頁 PDF 完整解析**：
  - 自動逐頁讀取 PDF 內容（單頁或多頁皆相容）。
  - 自動產出**「全部頁面合併總表」**工作表與**「各頁獨立工作表 (第 1 頁、第 2 頁...)」**。
  - 網頁介面提供直覺的「頁次切換器」，可逐頁切換表格與視覺對照圖。
- 📐 **空間幾何二維表格重構演算法**：
  - 根據文字框垂直高度與 Y 座標聚類為 **Row（列）**。
  - 根據水平座標與欄位分佈聚類為 **Column（欄）**，自動將零散字塊組裝回對齊的試算表格。
- 📊 **三合一多工作表 Excel 活頁簿 (.xlsx)**：
  1. `📋 全部頁面合併總表` 或 `📋 表格智慧還原`：套用商務藍白配色、斑馬紋與自適應欄寬，數字自動轉換為數值型別方便加總。
  2. `📄 各頁獨立工作表`：獨立各頁完整表格。
  3. `📝 辨識明細清單`：包含項次、文字、可信度百分比（綠/黃/紅條件著色）、X/Y 座標與寬高像素。
- 💻 **即時線上預覽與編輯**：
  - 網頁端即時呈現還原表格，人員可直接點擊儲存格校對修改，並提供視覺標註對照圖（Bounding Box Overlay）。
- 🌐 **雙軌連線與自動開窗**：
  - 伺服器啟動後自動於預設瀏覽器跳出操作畫面，並顯示本機與區網 IP 供同事連線。

```text
C:\GOOGLE ANGET\第一類_核心網頁與互動系統\OCR測試\
├── ocr_web_app.py          # FastAPI 主後端伺服器 (雙重OCR引擎、照片EXIF轉正、表格聚類、Excel活頁簿生成)
├── web_index.html          # 現代化前端操作介面 (支援拖曳/貼上上傳、多頁切換、線上即時編輯預覽、標註圖、下載)

├── .env                    # Google Gemini API Key 設定檔 (可選)
├── README.md               # 專案人類閱讀說明文件 (跨電腦同步防呆)
├── SKILL.md                # AI 助理閱讀與指令引導文件
├── ocr_test_tool.py        # 桌面版 Tkinter 輔助測試工具
├── run_test_tool.bat       # 桌面版啟動檔
├── ocr_compare_tool.py     # 單號核對輔助工具
├── run_compare_tool.bat    # 單號核對工具啟動檔
└── outputs/                # 產出之 .xlsx 暫存目錄
```

## ⚡ 啟動與執行步驟

雙擊執行資料夾內的 **`run_web_app.bat`**：
1. 視窗會顯示正在載入雙語模型與啟動伺服器。
2. 載入完成（約 5～8 秒）後，瀏覽器將**自動彈出**操作畫面 (`http://localhost:8000`)。
3. 人員可直接拖曳**照片（JPG/PNG/WEBP）**或**多頁 PDF 文件**進行判讀並下載 Excel！
