# 📦 勝一化工 - 產銷計畫表 Web 系統 (PWA 雙軌版 v7.0)

## 專案簡介
本專案為 **勝一化工 - 產銷計畫表 Web 系統**，直接對齊 Excel 產銷計畫原檔（`20260824產銷計畫.xlsx`），完整支援 **4 個月連續滾動生產與嚴謹結存連動**、**月份排程動態切換**、**隱藏無生產/需求產品**，並遵循全域 **PWA 雙軌架構規範**（包含獨立 Web 版與支援離線快取/桌面全螢幕的 PWA App 版）。

---

## 📐 100% 嚴謹連動公式（4 個月份滾動傳承）
1. **8/31 預估結存** = `08/24 期初庫存` + `8月生產總量 (數量1+2+3)` - `08/24~08/31 銷`
2. **9/30 預估結存** = `8/31 庫存` + **`9月生產總量 (數量1+2+3)`** - `09/30 銷`
3. **10/31 預估結存** = `9/30 庫存` + **`10月生產總量 (數量1+2+3)`** - `10/31 銷`
4. **11/30 預估結存** = `10/31 庫存` + **`11月生產總量 (數量1+2+3)`** - `11/30 銷`

---

## 🌟 核心功能亮點 (v7.0)
* 📑 **產銷總表置頂**：首頁第一個分頁直接呈現完整產銷總表，並提供精餾、初餾、調配、耗料 BOM、生產線別參照切換。
* 📅 **月份切換排程填報**：點選「8月 / 9月 / 10月 / 11月 排程」按鈕，即可切換填報當月 3 次生產期間（線別、日期區間、數量），即時連動最右側 4 個月結存。
* 👁️ **隱藏無生產/需求品項**：一鍵開關，自動過濾當月無庫存、無排程且無需求的產品。
* 🧪 **耗料 (BOM) 即時連動**：依據產品填報銷售量與物料係數，動態試算各原料總耗用噸數。
* 📱 **PWA 獨立 App 支援**：支援電腦 Chrome/Edge 一鍵安裝為獨立全螢幕視窗桌面 App，以及手機/平板新增至主畫面，具備 Service Worker 離線快取。
* ☁️ **雲端 GAS 串接節點**：內建 Google Apps Script 網址設定面板，可直接串接雲端資料庫。
* 📥 **CSV / Excel 報表匯出**：內建含 UTF-8 BOM 完整 CSV 匯出引擎，Excel 開啟不亂碼。

## 🚀 快速啟動與操作步驟
1. **本機 PWA 獨立 App 模式 (推薦)**：
   - 進入 `2_PWA_App版/`，雙擊 `啟動PWA本機測試.bat`。
   - 瀏覽器自動開啟後，點擊網址列右側「安裝」或頁面頂部「立即安裝」，即可將系統常駐於電腦桌面或手機主畫面！
2. **一般瀏覽器網頁模式**：
   - 直接雙擊 `點我開啟產銷計畫系統.bat` 或開啟 `1_Web_網頁版/index.html`。
