# 🛢️ IPA 崙尾動態生產排程與進耗存整合系統 (React 18 + Tailwind CSS)

## 專案簡介
本專案為建置於 Google Apps Script (GAS) 上之 **IPA 崙尾動態生產排程與進耗存整合系統**。採用 React 18 搭配 Tailwind CSS 構建現代化動態儀表板，具備 **多月份跨月庫存遞延繼承**、**線上動態增減產線**、**儲槽進耗存預估** 與 **歷史紀錄快照備份** 等核心功能。

## 🌟 核心功能亮點
*   **📅 多月份分頁連動 (4 個月份動態導覽)**：自動依據當月 (例如 9月) 計算顯示連續 4 個月份，支援跨年份顯示。
*   **🔗 跨月庫存遞延繼承**：前一個月最後一天的結存剩餘量，自動連動繼承為次月 1 號的期初庫存。
*   **➕ 動態增減產線**：支援線上即時新增/刪除產線 (如溶四~溶八)，可獨立調控流速 (T/hr)、進料槽與排料槽。
*   **📊 6 大儲槽進耗存試算**：精確試算 TK617/TK618 原料槽與 TK611/TK613/TK614/TK615 下腳料槽之每日進耗存剩餘。
*   **💾 歷史快照與雲端同步**：支援一鍵快照備份、讀取歷史檔案、清空歸零與 Excel (CSV) 報表匯出。

## 🚀 跨電腦一鍵啟動與推送
1. **環境初始化**：右鍵點擊 `setup_env.ps1` 執行，安裝 `@google/clasp` 工具。
2. **推送更新**：在 `src` 目錄下執行 `clasp push` 將原始碼同步推送到 Google Apps Script 專案。
