# IPA 專用動態生產排程與進耗存整合系統

## 專案簡介
這是一個建置於 Google Apps Script (GAS) 上的動態生產排程與進耗存整合系統。原本為通用版本，現已改為 **IPA 專用版**。系統具備前端儀表板介面（透過 HtmlService 呈現）以及後端試算表資料庫整合，能夠即時追蹤儲槽狀態、生產排程，並新增了「船隻位置追蹤」功能，協助掌握原料進港與耗存狀況。

## 核心功能亮點
*   **動態儀表板**：即時顯示目前庫存、進行中的排程與警報狀態。
*   **試算表整合 (DataStore)**：後端自動化寫入與讀取，將 Google Sheet 當作關聯式資料庫使用。
*   **歷史紀錄備份 (ArchiveStore)**：支援資料狀態的快照備份，確保操作歷程不遺失。
*   **🚢 船隻位置追蹤 (新功能)**：IPA 專用的船隻追蹤分頁，可隨時掌握載運原料的船隻動態。

## 跨電腦一鍵啟動與執行步驟
因為本專案的執行環境在 Google 雲端，本機端主要做為「程式碼開發與版本控制」之用。

1.  **環境初始化**：右鍵點擊 `setup_env.ps1` 選擇「使用 PowerShell 執行」，系統將自動檢查並安裝 Node.js 以及 `@google/clasp` 工具。
2.  **登入 Clasp**：在終端機輸入 `clasp login` 進行 Google 帳號授權。
3.  **拉取程式碼**：若尚未取得程式碼，請進入 `src` 資料夾執行 `clasp clone <Script_ID>`。
4.  **推送修改**：開發完畢後，在 `src` 目錄下執行 `clasp push` 將修改同步至 Google Apps Script 線上編輯器。
