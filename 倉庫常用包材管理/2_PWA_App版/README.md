# 倉庫常用包材管理與盤點系統 (PWA 獨立 App 版)

## 專案簡介
本專案為倉庫常用包材領用、進貨入庫、現場盤點與庫存水位監控之 PWA 應用程式版本，支援手機與平板現場即時盤點。

## 核心功能
- 📱 **手持 App 體驗**：倉管人員拿手機在貨架間走動盤點，隨開隨用
- 📦 **包材庫存監控**：即時警示安全水位與補貨需求
- ⚡ **PWA 離線快取**：倉庫訊號弱處亦能秒開系統
- 🖥️ **一鍵啟動測試**：雙擊 `啟動PWA本機測試.bat` 自動開啟伺服器

## 快速啟動
1. 雙擊 `啟動PWA本機測試.bat`
2. 於瀏覽器點擊「安裝」或「新增至主畫面」
