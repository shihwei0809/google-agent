# 勝一小包barcode對刷核對

這是一個輕量級的網頁版 QR Code 掃描核對工具，使用 HTML5 + JS 實作，並透過 Python FastAPI 建立本地伺服器供區域網路內的手機或平板連線使用。

## 系統需求
- Python 3.8+
- 行動裝置需與主機處於同一個 Wi-Fi 網域才能透過 IP 掃描。

## 執行與安裝方式
- **啟動方式**：直接雙擊 `啟動掃描系統.bat`，程式會自動檢查環境、安裝必要套件並啟動。
- **一鍵安裝**：也可以透過 `setup_env.ps1` 進行完整環境設定。

## 操作流程
1. 啟動後，畫面上會顯示 `http://<本機IP>:<Port>` 的網址。
2. 使用手機或平板的瀏覽器開啟該網址。
3. 依序掃描 **外包裝** 以及 **四個桶面** 的 QR Code。
4. 點擊「開始核對」按鈕。
5. 系統會依據料號、批號、DUNS 碼等規則進行比對，並顯示結果。
