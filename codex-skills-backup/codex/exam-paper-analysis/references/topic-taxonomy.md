# Taiwan Math Topic Taxonomy

Use this default taxonomy for Taiwan high-school math past-paper analysis unless the user asks for a custom classification.

## Recommended primary buckets

1. 平面幾何與解析幾何
2. 機率與統計
3. 多項式／方程式／代數結構
4. 空間幾何與空間向量
5. 圓錐曲線／投影／球面幾何
6. 三角函數與週期模型
7. 排列組合與計數
8. 指數與對數
9. 數列與規律
10. 矩陣

## Classification rule

- Assign one primary bucket per question.
- Choose the bucket that best explains the first decisive solving step.
- Do not double-count a question across multiple buckets unless the user explicitly asks for multi-tag analysis.

## Strategy mapping

- Lower-band improvement:
  - prioritize standard algebra, basic function handling, probability basics, and stable geometry setups
- Mid-band to high-band improvement:
  - prioritize integrated geometry, spatial reasoning, data interpretation, modeling, and multi-step translation
