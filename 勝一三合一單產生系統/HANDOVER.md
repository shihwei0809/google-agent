# 專案交接日誌 (HANDOVER.md) - 勝一三合一單產生系統

## 📌 專案建立背景
以「三合一單自動產生器」為母版，依據「勝一訂單」特定格式（包含空白班表、10~11 碼批號、指送地中文正規化）打造之獨立專案系統。

## 🎯 核心規格與技術點
1. **勝一訂單 Excel 解析**：
   - 自動辨識 空白班表 與 司機清單 分頁。
   - 自動讀取 批號、指送地、品名、預計到貨日期、到貨時間、司機、車牌、電話。
2. **批號與槽號提取**：
   - 支援 10~11 碼批號（如 26708S96T1、26707S125T1、26817E3051）。
   - 正則提取中間槽號（如 S96、S125、S405、E305、E319、S90、S82）。
3. **指送地正規化**：
   - 台積12廠P1 ➔ 12P1
   - 台積新竹14廠-P5 ➔ 14P5
   - 台積先進AP8 ➔ AP8
   - 台積AP7P1 ➔ AP7P1
   - 自動匹配 地點代號對照表.xlsx 帶出長代號。
4. **輸出目錄**：勝一三合一單輸出_YYYYMMDD，集中存放不干擾原系統。
5. **圖文手冊標準**：採用 manual_assets/ 靜態素材庫 + 0 Emoji + Word COM PDF 轉檔標準。
