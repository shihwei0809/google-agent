# 🚚 勝一三合一單產生系統 (Shinyi TSMC 3-in-1 & Dispatch System)

本系統專為勝一化工物流、排程與現場作業人員設計，以台積電槽車出貨排程與「勝一訂單」為核心，提供直觀易用的桌面圖形介面 (GUI)，能自動完成勝一訂單排程解析、槽號計算、二維條碼 (QR Code) 生成、COA 檢驗截圖 OCR 辨識自動嵌入，以及運輸通知表同檔併排修正卡片產出。

---

## 🌟 核心功能亮點 (Key Features)

- 📥 **勝一排程與訂單一鍵智慧匯入**：支援直接載入勝一排程（SNXM101 出貨通知單格式）與 `勝一訂單.xlsx`，支援由下往上倒數最新筆數擷取（5 筆、10 筆、全部）。
- 🧪 **五大槽車品項料號自動映射 (ShipQty=6000)**：
  - `CPNE4R` ➔ `L2C9173`（三合一單自動寫入 `4L2C9173`）
  - `SEP73E4` ➔ `L269100`（三合一單自動寫入 `4L269100`，並自動防呆修復 Excel 將 `SEP73` 誤轉 `1973-09-01` 問題）
  - `SEP73E5` ➔ `L2C9100`（三合一單自動寫入 `4L2C9100`）
  - `PMAHQ` ➔ `L2C9501`（三合一單自動寫入 `4L2C9501`）
  - `PMAHQ(R)` ➔ `L2R9501`（三合一單自動寫入 `4L2R9501`）
- 🏷️ **10~11 碼批號槽號與 TGCM 批號公式自動對齊**：全面支援勝一 10~11 碼批號（如 `26B05S93T1`、`26B03S120T1`），自動提取 `S93`、`S120` 槽號，並將三合一單 `C14`（TGCM 批號）動態設為 `=RIGHT(C7,10)` 或 `=RIGHT(C7,11)`，徹底解決 10/11 碼截斷問題。
- 📍 **全廠區 52 筆指送地智慧正規化與長代號轉換**：涵蓋 `FB30`、`12P1~P8`、`3廠`、`6廠`、`8廠`、`F20P1/P3`、`A6A0/A6B0`、`15P2~P7`、`15BP5A`、`A5B0`、`AP7P1/P2A/P2B`、`14P1~P6`、`18P1~P8`、`AP8`、`F22P1B`、`AP02D` 等完整對照表。
- 📄 **五種不同結構 COA 動態 Key-Based 產生与生产履歷 (Chemical_Lorry) 多欄自動對齊**：不再寫死 `B6/B7/B11/B12`，自動依 Column A 欄位名稱（`TSMCFab`、`FabPhase`、`ManufacturingDate`、`DeliverDate`、`RawLotId`、`ExpiryDate`、`RemainLifeTime`）更新，並支援 12~16 欄不同格式的 `Chemical_Lorry` 單列輸出。
- 🖼️ **COA 檢驗截圖 OCR 自動辨識**：一鍵上傳檢驗截圖，透過 Tesseract-OCR 自動辨識批號並精準裁切檢驗表頭與數據，自動嵌入三合一單 F5 儲存格。
- 📋 **防覆蓋獨立檔名與當日歸檔**：
  - 獨立三合一單：[出貨日期]. [地點]_[槽號]_台積電槽車barcode三合一單.xlsx
  - 歸檔資料夾：勝一三合一單輸出_YYYYMMDD（一天產出多次自動集中存放）。
- 📑 **運輸通知表接力與併排修正卡片**：同天多次出車自動接力寫入；填寫修正時間自動於右側併排生成紅字加粗與刪除線修正卡片。

## 🚀 跨電腦一鍵啟動與執行步驟

1. **首次使用**：雙擊 setup_env.ps1 或直接雙擊 啟動_勝一三合一單產生器.bat（會自動為您安裝缺少的 Python 套件）。
2. **日常使用**：
   - 雙擊 啟動_勝一三合一單產生器.bat 開啟主介面。
   - 點擊「從 Excel 匯入」選取 勝一訂單.xlsx，自動填入排程。
   - 勾選欲產生的項目後，點擊「開始批次產生 Excel 報表」。
3. **查閱手冊**：雙擊 一鍵產生圖文手冊.bat 即可隨時更新並開啟最新 PDF 操作手冊。
