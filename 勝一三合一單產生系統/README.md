# 🚚 勝一三合一單產生系統 (Shinyi TSMC 3-in-1 & Dispatch System)

本系統專為勝一化工物流、排程與現場作業人員設計，以台積電槽車出貨排程與「勝一訂單」為核心，提供直觀易用的桌面圖形介面 (GUI)，能自動完成勝一訂單排程解析、槽號計算、二維條碼 (QR Code) 生成、COA 檢驗截圖 OCR 辨識自動嵌入，以及運輸通知表同檔併排修正卡片產出。

---

## 🌟 核心功能亮點 (Key Features)

- 📥 **勝一訂單一鍵智慧匯入**：直接載入 勝一訂單.xlsx（自動辨識「空白班表」及各欄位），支援由下往上倒數最新筆數擷取（5 筆、10 筆、全部）。
- 🏷️ **10~11 碼批號槽號自動提取**：全面支援勝一 10~11 碼批號（如 26708S96T1、26707S125T1、26817E3051），精準提取 S96、S125、S405、E305、E319 槽號。
- 📍 **指送地智慧正規化與長代號轉換**：自動清理地點文字（如 台積12廠P1 ➔ 12P1、台積新竹14廠-P5 ➔ 14P5、台積先進AP8 ➔ AP8），並自動匹配地點代號對照表。
- 🖼️ **COA 檢驗截圖 OCR 自動辨識**：一鍵上傳檢驗截圖，透過 Tesseract-OCR 自動辨識批號並精準裁切檢驗表頭與數據，自動嵌入三合一單 F5 儲存格。
- 📋 **防覆蓋獨立檔名與當日歸檔**：
  - 獨立三合一單：[出貨日期]. [地點]_[槽號]_台積電槽車barcode三合一單.xlsx
  - 歸檔資料夾：勝一三合一單輸出_YYYYMMDD（一天產出多次自動集中存放）。
- 📑 **運輸通知表接力與併排修正卡片**：同天多次出車自動接力寫入；填寫修正時間自動於右側併排生成紅字加粗與刪除線修正卡片。

## 🚀 跨電腦一鍵啟動與執行步驟

1. **首次使用**：雙擊 setup_env.ps1 或直接雙擊 啟動_勝一三合一單產生器.bat（會自動為您安裝缺少的 Python 套件）。
2. **日常使用**：
   - 雙擊 啟動_勝一三合一單產生器.bat 開啟主介面。
   - 點擊「從 Excel 匯入」選取 勝一訂單.xlsx，自動填入排程。
   - 勾選欲產生的項目後，點擊「開始批次產生 Excel 報表」。
3. **查閱手冊**：雙擊 一鍵產生圖文手冊.bat 即可隨時更新並開啟最新 PDF 操作手冊。
