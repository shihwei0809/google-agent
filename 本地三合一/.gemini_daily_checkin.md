# 每日開工確認與同步規範 (Daily Start Check-in & Auto-Sync Protocol)

## 觸發條件
當每日系統時間更新，或偵測到使用者對話提及「開工」、「開始工作」或當天第一次互動時觸發。

## 執行步驟
1. **自動拉取收工備份**：
   - 執行 `C:\GOOGLE ANGET\AutoStartWork.ps1` 自動拉取 GitHub `main` 及 `auto-backup` 分支並合併最新程式碼。
2. **系統狀態回報**：
   - 當前日期與時間
   - 本地服務與背景任務運行狀態（如：HTTP Server 8000 / Python 服務）
3. **開工確認與目標列出**：
   - 列出上次/昨日完成之項目與今日預計推動之主目標。
4. **確認後開始執行**。
