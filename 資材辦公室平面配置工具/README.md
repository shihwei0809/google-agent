# 資材辦公室 2D/3D 互動平面配置工具

> 2027 年資材辦公室空間不足改善規劃專用工具，100% 依公分尺寸還原刀把形格局（585 × 1295 cm），支援 **2D 拖拉配置 ＋ Three.js 即時 3D 立體預覽**。

## 核心功能亮點
- **1 cm 精準比例還原**：刀把形外框（上方儲藏室 585×270、主要辦公區 585×500、辦公延伸區 345×525）、2 處結構柱、2 處出入口與全部現有辦公桌、系統高櫃、矮櫃與家電。
- **2D / 3D 分割同屏連動**：在 2D 拖拉移動、按 `R` 鍵旋轉 90° 或調整長寬高，右側 3D 畫面即時同步呈現真實高度（280cm 高櫃 / 110cm 矮櫃 / 75cm 辦公桌）。
- **空間碰撞紅框警示**：桌櫃超出刀把形牆界、撞到結構柱或互相重疊時，自動亮紅框提醒。
- **多方案對比**：內建「現況配置 (v6)」、「2027 改善提案 A（動線釋放）」、「2027 改善提案 B（擴編 26 位）」，並支援新增桌櫃與匯入/匯出方案 JSON。
- **一鍵匯出高清 2D 平面圖 (`.png`)**：可直接貼入 2027 工作規劃簡報或 Word 文件。

直接雙擊 `點我開啟資材辦公室2D3D配置工具.bat` 或開啟 `1_Web_網頁版\index.html` 即可使用（自動存檔於瀏覽器 `localStorage`）。
