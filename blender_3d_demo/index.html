🤖 用 Antigravity + Blender MCP 改這個 3D 場景

這個 3D 倉庫檔案已同步存放在資料夾內的 warehouse_scene.blend，你可以用純中文叫 AI 幫你現場改模型：

  1. 雙擊資料夾內的 warehouse_scene.blend 用 Blender 打開。
  2. 在 Blender 視窗按鍵盤 N 鍵叫出右側邊欄，切換到 MCP for Blender 標籤。
  3. 點擊 Connect to MCP server（或 Start MCP Server）。
  4. 回到 Antigravity 對話框打字許願，例如：
    「把 B 區貨架再加高一層，並在走道多放一台黃色堆高機，然後重新匯出 warehouse_3d.glb」

💡 若剛設定完 mcp_config.json，重開一次 Antigravity 視窗即可在右上角 ... > MCP Servers 看到 blender 綠燈連線。
