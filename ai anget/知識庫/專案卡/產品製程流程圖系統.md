# 📌 產品製程流程圖系統

- **專案類型**: 核心開發專案
- **本機目錄**: `c:\GOOGLE ANGET\flowchart-web`
- **技術棧**: `HTML, CSS, JavaScript。`

## 📝 專案用途
鴻勝化學的「產品製程流程圖系統 (槽體製程管控系統)」。

## ✨ 功能特色
- 提供側邊欄導航、圖例說明（原料、製程、成品槽、格外品）、 SVG 互動式流程圖畫布。支援匯入/匯出備份功能，以及點擊槽體跳出詳細資訊（包含液位動態視覺、溫度、壓力、成分狀態），並支援 N2 吹掃模擬。
