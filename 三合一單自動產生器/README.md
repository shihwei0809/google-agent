## 簡介
這是一個使用 Python Tkinter 製作的桌面自動化工具，設計用來快速產生多個送達地點的「三合一單」獨立 Excel 檔案以及彙整格式的「運輸通知表」Excel 檔案。

## 核心功能亮點
* **圖形介面 (GUI)**：直覺易用的桌面視窗，支援複製貼上多筆資料或 Excel 直接匯入。
* **雙報表產出**：
  1. **三合一單 Excel**：自動填入槽號、批號、送達地點並生成專屬條碼 QR Code。
     - **檔名規格**：`[出貨日期]. [地點]台積電槽車barcode三合一單.xlsx`（例如：`2026.8.18. 18P3B台積電槽車barcode三合一單.xlsx`）。
  2. **運輸通知表 Excel**：產生精美格式化的出貨排程通知卡片表（含廠區台積地點、槽號亮黃背景、預計與修正到廠時間刪除線特效、併排修正通知卡片等）。
* **當天日期資料夾資料歸檔**：
  - 產出的 Excel 檔案統一歸檔至 `三合一單輸出_YYYYMMDD` (如 `三合一單輸出_20260818`)，方便人員快速尋找並存取當日檔案。
* **同檔併排「出貨排程修正通知」卡片**：
  - 當輸入「修正到廠時間」時，在 `運輸通知表.xlsx` 的同一分頁右側（H~M 欄）自動併排生成「出貨排程修正通知」卡片。
  - 第一個預計時間標上刪除線，修正時間以紅字加粗填寫於下方。

## 如何使用
1. 雙擊執行 `啟動_三合一單產生器.bat`。
2. 系統自動確認 Python 環境與依賴套件後啟動視窗。
3. 填入或貼上「批號」、「地點」，系統會自動帶出「槽號」與「長代號」。
4. 點擊出貨日期旁邊的 `📅` 按鈕開啟日曆選擇日期，輸入「預計到廠時間」及（若有修改）「修正到廠時間」。
5. 勾選欲產生的報表種類（三合一單 / 運輸通知表），點擊「🚀 開始批次產生 Excel 報表」。
6. 產出的檔案會存放於當天日期的 `三合一單輸出_YYYYMMDD` 資料夾並自動開啟。
