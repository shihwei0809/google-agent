# 三合一單自動產生器

## 簡介
這是一個使用 Python Tkinter 製作的桌面小工具，設計用來快速產生多個送達地點的「三合一單」Excel 檔案。

## 功能亮點
* **圖形介面 (GUI)**：提供簡單的桌面視窗供人員操作，無需具備程式背景。
* **自動批次處理**：只要輸入一次「槽號」與「批號」，然後貼上多個「送達地點」，系統就會自動為每個地點產生一份獨立的 Excel 檔案。
* **保留原格式**：自動寫入 C5、C7、C11 欄位，並保留原本 Excel 內的其他格式與函數（如 Barcode）。

## 檔案結構
* `main.py`：主程式碼 (Tkinter + openpyxl)。
* `啟動_三合一單產生器.bat`：一鍵啟動腳本，會自動安裝 `openpyxl` 並開啟應用程式。
* `README.md` / `SKILL.md`：說明與技能文件。

## 如何使用
1. 直接雙擊 `啟動_三合一單產生器.bat`。
2. 系統會自動檢查/安裝需要的套件，接著彈出操作視窗。
3. 確認 Excel 範本路徑正確。
4. 輸入「槽號」與「批號」。
5. 在下方文字框貼上所有的「送達地點」（一行一個）。
6. 點擊「開始產生三合一單」，完成後會自動打開輸出的資料夾。
