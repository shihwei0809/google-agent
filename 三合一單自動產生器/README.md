# 三合一單自動產生器 & 運輸通知表產生器

## 💡 專案簡介
這是一個使用 Python Tkinter 開發的桌面自動化工具，設計用來取代手動製作三合一單與運輸通知表的繁瑣流程，大幅提升出貨人員的工作效率。

## ✨ 系統核心功能與亮點
* **超高畫質 AI 截圖辨識 (Tesseract OCR)**
  - 自動讀取上傳的 COA 截圖，內建 Lanczos 兩倍放大演算法確保文字極度清晰。
  - AI 自動辨識圖片內的批號，並以「神經外科手術級」的極限邊距精準裁切對應的資料列。
  - 將裁切好的 COA 圖片自動無縫拼貼入 Excel 範本，精確鎖定原廠設定尺寸 (寬 22.95cm × 高 11.9cm)，完美填滿框線。
* **智慧雙引擎 Excel / CSV 多檔自動匯入**
  - 支援 Ctrl 多選檔案一次匯入大量資料。
  - **自動判定引擎**：無論是「中文橫向表格」還是「單筆英文直向 (Key-Value) CSV」，系統皆能自動判定。
  - 自動從檔名 (如 ...18P3B_6989.csv) 精準擷取地點代號，並自動抽取 RawLotId 與 DeliverDate。
* **無批號自動防重複檔名機制**
  - 產生的檔案名稱預設隱藏批號，若遇同地點同日期的情況，系統自動加上序號 (如 15P5_1_...)，防止檔案覆蓋。
* **AI 智慧防呆安裝引導**
  - 當使用者點擊「上傳 COA 截圖」但尚未安裝 OCR 核心引擎時，系統不會報錯，而是自動彈出友善提示，並一鍵引導開啟官方下載網頁，讓非工程人員也能輕鬆完成環境設定。
* **雙報表一鍵生成**
  - **三合一單 Excel**：自動帶入槽號、料號、長代號，並動態產生 QR Code 與 COA 截圖。
  - **運輸通知表 Excel**：自動將多筆資料按「出貨日期、地點、槽號」統整，並自動加入「修改到廠時間」的紅色戳記與括號說明。

## 🚀 一鍵啟動與操作步驟
1. 雙擊執行 啟動_三合一單產生器.bat。
2. 系統會自動檢查並安裝所需的 Python 套件 (如 openpyxl, qrcode, Pillow, pytesseract)。
3. 開啟介面後，可點擊 **「📥 從 Excel 匯入」** 批次匯入資料，或手動貼上「批號」、「地點」。
4. 點擊 **「🖼️ 上傳 COA 截圖」** (系統會自動協助您安裝 OCR 引擎)，上傳當日的查詢結果截圖。
5. 點擊 **「🚀 開始批次產生 Excel 報表」**。
6. 產生的所有 Excel 檔案會自動儲存至當日日期資料夾 (如 三合一單輸出_20260827) 並自動為您開啟資料夾。
