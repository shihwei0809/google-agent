# 技能說明

這是一個使用 Python Tkinter + openpyxl 撰寫的自動化工具。

## 執行與安裝
- 工具採用 Python 撰寫。
- 所需套件：`openpyxl`, `qrcode`, `pillow` (Tkinter 為 Python 內建)。
- 人員只需要執行 `啟動_三合一單產生器.bat`，就會自動處理 Python 依賴安裝並開啟 GUI 畫面。
- 人員完整操作步驟請參閱 `三合一單與運輸通知表自動產生器_操作手冊.docx` 或 `.pdf`。

## 特殊邏輯與報表類型
1. **三合一單 Excel**：
   - 根據使用者的需求，工具會寫入指定範本的 C5(槽號)、C7(批號)、C11(送達地點)，並重新產生條碼/QR Code。
   - **檔名命名規則**：`[出貨日期]. [地點]台積電槽車barcode三合一單.xlsx` (例：`2026.8.18. 18P3B台積電槽車barcode三合一單.xlsx`)。
2. **運輸通知表 Excel**：
   - 將勾選之排程項目依指定格式彙整為排程通知卡片表。
   - 含出貨日期、星期、預計到廠時間、修正到廠時間、廠區 (台積 + 地點)、槽號 (亮黃背景顯眼標記) 等欄位。
   - **同檔併排「出貨排程修正通知」**：當有輸入「修正到廠時間」時，在 `運輸通知表.xlsx` 的同一分頁右側（H~M 欄）自動併排生成「出貨排程修正通知」卡片，預計時間標上刪除線，修正時間以紅字加粗強調。
3. **當天日期資料夾**：
   - 輸出的檔案會自動放置在 `三合一單輸出_YYYYMMDD` (如 `三合一單輸出_20260818`) 資料夾內，以當天日期命名，方便人員存取與抓檔。
