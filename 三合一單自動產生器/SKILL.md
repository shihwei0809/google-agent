# 技能說明

這是一個使用 Python Tkinter 撰寫的自動化工具。

## 執行與安裝
- 工具採用 Python 撰寫。
- 所需套件僅有 `openpyxl` (Tkinter 為內建)。
- 人員只需要執行 `啟動_三合一單產生器.bat`，就會自動處理 Python 依賴安裝並開啟 GUI 畫面。

## 特殊邏輯
- 根據使用者的需求，工具會寫入指定範本的 C5(槽號)、C7(批號)、C11(送達地點)。
- 輸出的檔案會放置在與範本同一個目錄下的 `三合一單輸出_[時間]` 資料夾內，避免覆蓋原本的範本檔案。
