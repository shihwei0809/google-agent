# 溫度通報系統 — 版本更新與修訂紀錄 (CHANGELOG)

本文件記錄了「彰化縣線西鄉環境溫度監控與通報系統」各版本的更新細節與功能演進，方便不同設備與管理人員追蹤系統異動。

---

## 📅 版本歷史

### v4.7 (2026-06-12) — 當前最新版本
*   **精準整點心跳排程與本機節流**：
    *   放寬本機 Python 監控時段為 `07:00 - 24:00`，使 `07:58` 首次執行不被過濾。
    *   配合 60 分鐘本機節流與 `last_notified.json` 校準，精準鎖定在每日 `07:58`, `08:58`, ..., `23:58` 執行，完成最後一次安全心跳監測。
*   **試算表與 Firestore 雙向即時同步**：
    *   重構 `syncHistoryLogsToFirebase` 歷史同步機制，比對並自動 `DELETE` 移除在試算表中已被管理員手動刪除的歷史文檔。
    *   實作 Apps Script `onChange` 安裝式監聽器，凡是手動增刪修改試算表，皆即時自動同步至 Firebase，無需手動按鈕。
*   **HMI 歷史查詢按鈕修復**：
    *   修復 `firebase_hmi/app.js` 全域變數重複宣告 JS 語法錯誤，使「歷史查詢」按鈕在線上儀表板可流暢查詢。

### v4.6 (2026-06-12)
*   **雙模溫度趨勢圖 (Trend Chart)**：
    *   Firebase HMI 與 Google Apps Script 雲端後台全面整合 Chart.js，支援「即時 24H」與「歷史範圍查詢」雙模切換。
    *   內建等距降採樣（Downsampling）演算法，在查詢 1-2 個月等數千點歷史數據時自動降至 200 點內，徹底解決瀏覽器與手機卡頓問題。

### v4.5 (2026-06-11)
*   **三態心跳燈標示**：
    *   HMI 儀表板引入 🟢 在線（本機正常）、🟡 雲端監控（本機異常，由雲端接管）、🔴 離線警報（本機與備援均中斷）三態心跳燈，提升管理直觀性。
*   **GAS 網頁安全防護與響應式介面**：
    *   GAS 網頁端新增密碼驗證（預設 `admin888`）與安全登出機制，手機版介面自動折疊與手勢滑動支援。

### v4.1 (2026-06-11)
*   **本機 Python 雙寫備援整合**：
    *   本機 `weather_monitor.py` 在執行觀測時同時向 GAS 網頁 API 與 Firebase Firestore 寫入，確保雙軌系統一致性。

### v4.0 (2026-06-11)
*   **Firebase HMI 雲端人機介面發布**：
    *   正式部署 Firebase Hosting 儀表板，即時監控即時溫度、閥值、聯絡人清冊及警報通報狀態，資料毫秒級同步。

### v3.4 (2026-06-11)
*   **試算表自訂欄寬調整**：
    *   新增「重設欄寬為最佳預設」自訂選單，並在新建月份紀錄表時自動排版，同時手動修改時亦不會被自動覆蓋。

### v3.2 (2026-06-11)
*   **氣象觀測站更換為伸港站 (10分鐘更新)**：
    *   **高頻率數據監控**：將氣象觀測數據源由「線西站 (`C0G900`)」改為鄰近的「伸港站 (`C2G870`)」，並將資料庫 API 從每小時更新的 `O-A0001-001` 切換為每 10 分鐘更新的 `O-A0003-001`，顯著降低資料延遲。
    *   **操作說明書同步更新**：同步修訂說明書，詳細備註本廠區與更換氣象站的原因。

### v3.1 (2026-06-10)
*   **欄寬美化與自訂控制**：
    *   **建立分頁時自動美化**：新建月份紀錄表（如 `紀錄_2026-06`）時，自動將 6 個欄位寬度設定為最美觀的寬度（通報時間與觀測時間 170px、警報與通知狀態 140-200px），省去手動拉寬的困擾。
    *   **保護使用者拉寬設定**：日常新增紀錄時不再重設欄寬，完美保留使用者手動拉寬的版面設定。
    *   **新增「重設欄寬」選單功能**：在頂端自訂選單新增 **`📏 重設欄寬為最佳預設`**，供管理員隨時一鍵回復最美觀的版面。

### v3.0 (2026-06-10)
*   **指標切換**：全面改用氣象署線西站的**一般環境溫度 (AirTemperature)**，取代體感溫度，提升監測穩定性。
*   **每小時持續寫入紀錄**：不論是否觸發警報，系統每小時固定寫入當前觀測值至試算表當月 `紀錄_YYYY-MM` 分頁中留底。
*   **本機心跳同步寫入**：本機電腦完成排程觀測後，會自動透過心跳 Webhook 將溫度與通報狀態傳送給雲端 Web App，並由 Web App 代為寫入試算表紀錄。
*   **設備提醒語復原**：警報主體內容中重新加入 `※ 請相關人員開啟灑水設備降溫循環過濾器。` 操作指引。
*   **修復 Apps Script 變數 Bug**：
    *   修復 `doPost` 中誤用未定義變量 `props` 的問題（已正名為 `props`）。
    *   修復手動測試功能 `testNotifyForce` 內誤用未定義變量 `currentAT` 的問題（已改用 `currentTemp`）。
*   **時間格式優化**：將觀測時間由 ISO 格式（含 `T` 與 `+08:00`）優化為易讀的 `YYYY-MM-DD HH:mm:ss` 格式。

### v2.2 (2026-06-09)
*   **狀態機監控模式**：引進每小時狀態機監控（`HOT` / `COOL` 雙態狀態機），在溫度首次超標時發送「高溫超標警報」，在首次降回安全溫度時發送「溫度回落正常通知」，持續處於同狀態下則防重複通知。
*   **時段限制**：限制警報監控時段為 `08:00 - 24:00`，避免非工作時間打擾相關人員。
*   **自動查詢 LINE ID**：內建 `doPost(e)` Webhook。當人員在群組或聊天室內發送關鍵字（如 `id`, `查詢id`）時，系統會自動擷取 ID 並記錄在試算表第一頁最底端。
*   **LINE 推播相容性優化**：
    *   相容 `R` 或 `r` 開頭的多人聊天室 ID。
    *   相容大小寫字母容錯（自動將輸入的首字母轉為大寫）。
    *   在 LINE 群組推送失敗時，於 Apps Script 執行記錄中輸出明確報錯，方便工程人員排查。
*   **歷史紀錄分頁優化**：自動按月建立 `紀錄_YYYY-MM` 分頁，美化表頭格式，並支援舊資料表頭自動平滑遷移。

### v1.0 (2026-06-08) — 初始發布版本
*   **核心功能**：實現對線西鄉氣象觀測數據的定時抓取與 LINE、Email 自動警報發送。
*   **名單管理**：支援從 Google 試算表（聯絡人設定檔）中直接讀取聯絡名單與啟用狀態（Enabled 欄位）。
*   **溫度閾值**：支援從試算表內以 `Threshold` 或 `溫度閾值` 指定警報閥值，本機設定自動服從雲端設定。
