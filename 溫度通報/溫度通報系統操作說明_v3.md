# 彰化縣線西鄉環境溫度監控與通報系統 — 操作與維護說明書 (v3.0)

> 更新日期：2026-06-11　　版本：v3.0（新增 Firebase 即時儀表板）

本系統整合了**本機 Python 排程程式（主要端）**、**Google Apps Script 雲端腳本（備援端）**，以及全新的 **Firebase 即時監控儀表板（HMI）**，實現 24 小時不間斷的天氣觀測、雙向狀態同步，並提供可在任意裝置瀏覽器開啟的即時監控網頁。

## 🖥️ Firebase HMI 儀表板使用說明

### 開啟網頁

在任意裝置（電腦、手機、平板）的瀏覽器開啟：

```
https://hongsheng-temp-523.web.app
```

不需要安裝任何程式，資料每秒即時更新。

---

### 儀表板各功能說明

#### 📊 儀表板（首頁）

| 顯示項目 | 說明 |
|---------|------|
| 環形溫度計 | 即時環境溫度，圓環顏色隨溫度狀態變色 |
| 警報閾值 | 目前設定的超標溫度（°C） |
| 監控時段 | 每日監控的開始與結束時間 |
| 雲端監測頻率 | GAS 雲端備援的執行間隔 |
| 雲端備援機制 | 固定顯示「運作中」 |
| 本機監控端心跳 | 顯示最後一次收到本機或雲端心跳的時間 |

#### 本機監控端心跳三種狀態

| 顯示 | 顏色 | 說明 |
|------|------|------|
| 在線 (正常) | 🟢 綠色 | 本機電腦正常運作中 |
| 雲端監控（本機異常）| 🟡 琥珀色閃爍 | 本機異常，雲端備援已接手 |
| 離線警報 | 🔴 紅色 | 本機與雲端皆無心跳，請立即檢查 |

---

#### ⚙️ 系統設定（需管理密碼）

1. 點選左側選單「系統設定」
2. 輸入管理密碼（預設：`admin888`）
3. 可調整以下設定並儲存：
   - 溫度警報閾值（°C）
   - 每日監測開始／結束時間
   - 監測頻率（分鐘）
   - 管理密碼

> **⚠️ 注意**：HMI 目前的設定儲存只更新 Firebase，若要同步更新 GAS 和試算表，需同時在 GAS 選單操作或透過 `sync_sheet_to_firebase.py` 重新同步。

---

#### 👥 聯絡名冊（需管理密碼）

- 新增、停用、刪除 LINE/Email 通報對象
- 修改後點「儲存名冊」即即時生效

---

#### 📋 通報紀錄

顯示歷史通報明細，欄位說明：

| 欄位 | 說明 |
|------|------|
| 通報時間 | 系統執行通報的時間 |
| 溫度閾值 | 當時設定的警報溫度 |
| 環境溫度 | 當時觀測到的實際溫度 |
| 氣象觀測時間 | CWA 氣象站的觀測時間 |
| 警報狀態 | 正常(未超標)／高溫超標警報／溫度回落正常 |
| 通知管道 / 執行端 | LINE、Email 已發送或未發送，以及執行端別 |

**警報狀態顏色說明：**
- ⬛ 灰藍色：正常（未超標）
- 🟢 綠色：溫度回落正常（警報解除）
- 🔴 紅色：高溫超標警報

**搜尋與匯出：**
- 右上角輸入關鍵字可即時篩選
- 點「匯出 CSV」可下載全部紀錄

---

### 2. 必要檔案確認

執行前請確認以下檔案存在於 `C:\GOOGLE ANGET\溫度通報\`：

| 檔案 | 說明 |
|------|------|
| `config.json` | 本機設定檔 |
| `firebase_key.json` | Firebase Service Account 金鑰（勿公開） |
| `weather_monitor.py` | 主程式 |
| `sync_sheet_to_firebase.py` | 手動補同步工具 |

---

### 3. 設定 Windows 工作排程器

1. 按 `Win + R` 輸入 `taskschd.msc` 開啟工作排程器
2. 右側點擊「建立基本工作」，輸入名稱（例如：`溫度通報系統`）
3. 觸發程序選擇「每天」
4. 動作選擇「啟動程式」：
   - **程式或指令碼**：`python`（或完整路徑）
   - **新增引數**：`weather_monitor.py`
   - **開始位置**：`C:\GOOGLE ANGET\溫度通報`
5. 儲存後，對工作按右鍵 → 「內容」→ 「觸發程序」→ 勾選「重複工作間隔」設為 **1 小時**，持續「無限期」

## ☁️ 雲端備援設定

### 1. 更新 Google Apps Script

1. 開啟 Google 試算表 → 擴充功能 → Apps Script
2. 點選 `Code.gs`，全選後貼上最新版 `Code.gs` 內容
3. 儲存（Ctrl+S）
4. 部署 → 管理部署 → 建立新版本 → 部署

### 2. GAS 觸發條件設定

在 Apps Script 左側「觸發條件（時鐘圖示）」設定：
- 執行功能：`checkWeatherAndNotify`
- 時間型觸發：每小時執行一次

### 3. Firebase 欄位說明

GAS 備援執行時，Firebase `realtime_data/status` 中的 `heartbeat_source` 欄位會設為 `"cloud"`，HMI 儀表板因此顯示 **「雲端監控（本機異常）」**，人員可立即判斷本機狀態。

## 🔧 手動補歷史資料工具

`sync_sheet_to_firebase.py` 可在以下情況使用：

- 首次建置，需將 Google Sheet 歷史資料同步至 Firebase
- Firebase 資料遺失，需從 Sheet 重新匯入
- 批量修正歷史資料欄位

**執行方式：**
```cmd
cd "C:\GOOGLE ANGET\溫度通報"
python sync_sheet_to_firebase.py
```

執行後會自動讀取當月（月初5天內另讀上月）的試算表歷史並寫入 Firebase。

## 🕹️ 日常維護操作

### 試算表選單操作（GAS 端）

開啟 Google 試算表，頂端選單列「🌡️ 溫度通報系統」：

| 選單項目 | 功能 |
|---------|------|
| 🧪 測試即時通報 | 強制發送當前溫度通報（忽略時段與鎖定） |
| ⚙️ 套用設定並更新排程 | 重新讀取設定並重建觸發條件 |
| 🔄 同步資料至 Firebase | 手動一鍵將設定、聯絡人、歷史推送至 Firebase |
| 🔄 重置防重複鎖定 | 清除重複通知狀態，下次超標將再次通報 |
| 📏 重設欄寬為最佳預設 | 整理當月紀錄分頁的欄位寬度 |

### 快速功能測試（HMI 端）

在 Firebase HMI 儀表板首頁下方（需管理密碼）：
- **強制測試**：觸發測試通報，確認 LINE/Email 是否暢通
- **重置鎖定**：同試算表選單「重置防重複鎖定」

## 📊 歷史紀錄查詢

**Google 試算表：** 自動建立 `紀錄_YYYY-MM` 分頁（如 `紀錄_2026-06`）

**Firebase HMI：** 通報紀錄頁，最多顯示最近 100 筆，可搜尋、匯出 CSV

歷史紀錄欄位說明：
- `(本機執行)` — 由公司桌機本機排程執行
- `(本機執行 (心跳))` — 本機執行但未超標，只發送心跳
- `(雲端備援)` — 本機無心跳，由 GAS 雲端接管

## 🔒 安全注意事項

| 項目 | 說明 |
|------|------|
| `firebase_key.json` | Service Account 私鑰，**請勿分享或公開** |
| `config.json` | 包含 LINE Token 與 Gmail 密碼，**請勿分享** |
| HMI 管理密碼 | 預設 `admin888`，**建議上線後立即修改** |
| Firestore 安全規則 | 目前設定為公開讀寫，若需要限制存取請至 Firebase Console 調整規則 |
