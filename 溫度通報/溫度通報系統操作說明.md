# 彰化縣線西鄉環境溫度監控與通報系統 — 操作與維護說明書 (v4.1)

本系統整合了**本機 Python 排程程式（主要端）**與 **Google Apps Script 雲端腳本（備援端與 HMI 門面）**，實現 24 小時不間斷的天氣觀測與雙向狀態同步，當溫度高於設定閾值時將發送 LINE 及 Email 通知。

---

## 🧭 系統架構與運作邏輯
```
                        ┌─────────────────────────┐
                        │   Google 試算表 (雲端)   │
                        └────────────┬────────────┘
                                     │ (RPC 通訊 / 試算表讀寫)
                  ┌──────────────────┴──────────────────┐
                  ▼                                     ▼
       ┌─────────────────────┐               ┌─────────────────────┐
       │  本機 Python 腳本   │               │   HMI 人機管理網頁  │
       │   (每小時定時排程)   │               │   (Web App 瀏覽器)   │
       └──────────┬──────────┘               └──────────┬──────────┘
                  │ (POST 心跳訊號)                     │ (google.script.run)
                  │                                     │
                  ▼                                     ▼
       ┌─────────────────────────────────────────────────────┐
       │           Google Apps Script 雲端處理中心            │
       │  - doGet(e) ：偵測到瀏覽器請求，輸出 HMI 網頁畫面     │
       │  - doPost(e)：接收本機心跳與狀態同步數據            │
       │  - 備援排程  ：若本機無心跳，雲端自動接管溫度監測與通知│
       └─────────────────────────────────────────────────────┘
```

1. **本機主要端**：透過 Windows 工作排程器每小時執行一次，執行時會先與雲端同步警報狀態，並在執行完成後向雲端發送心跳與觀測數據。
2. **雲端備援端**：每小時排程啟動時檢查本機心跳。若本機在指定時間內有活躍紀錄，雲端會自動跳過本次排程；若本機電腦關機或網絡中斷（無心跳），雲端將接管觀測並發送通知，並在通報紀錄中註記 `(雲端備援)`。
3. **雲端人機端 (HMI)**：當人員開啟 Web App 網址時，會顯示響應式的深色科技風人機網頁，不需進入試算表即可修改閾值/時段、管理聯絡人並查詢與匯出歷史溫度紀錄。

### 📊 觀測溫度數據來源
* **數據來源**：中華民國交通部中央氣象署 (CWA) 開放資料平台 API (資料集編號：`O-A0003-001`)。
* **抓取站點**：彰化縣伸港鄉「伸港觀測站」（站點編號：`C2G870`），提供 10 分鐘即時更新。
* **抓取指標**：即時環境溫度/乾球溫度（即氣象署 API 中的 `AirTemperature` 欄位）。

## 🖥️ HMI 人機介面操作指南 (已針對手機端與密碼保護優化)

管理人員不需直接開啟 Google 試算表。只需在瀏覽器（支援手機與電腦）開啟部署所取得的 **Web App 網址**，即可進行所有日常維護：

### 🔑 安全防護與登出
* **身份驗證**：進入「系統設定」、「聯絡人名冊」或點擊測試按鈕時，系統會要求輸入管理密碼。預設密碼為 **`admin888`**。
* **解鎖工作**：成功解鎖後即可進入操作，並且會在瀏覽器階段快取（Session）中保存登入狀態。
* **安全登出**：點擊網頁右上角（或側邊欄最下方）的「登出」按鈕，即可清除快取狀態，重新鎖定網頁，防止其他人操作。

### 📱 手機介面特別優化
* **底部導覽列**：使用手機存取時，系統會將左側選單優化為底部懸浮導覽列，符合行動單手操作。
* **Swipe 表格滑動**：表格欄位支援手勢橫向滑動，避免資料擠壓變形，方便在小螢幕查看 LINE ID 與 Email。

### 1. 📊 狀態儀表板 (Dashboard)
- **即時氣溫圓形儀表 (Gauge)**：大字顯示伸港測站最新溫度，顏色會依據氣溫自動轉變（正常：綠色、接近閾值：黃色、超標：紅色呼吸發光）。
- **氣象發布時間**：顯示中央氣象署最新氣溫發布的時間。
- **本機心跳狀態**：顯示本機 Python 程式最後執行時間與「在線/離線狀態」。若狀態顯示「離線警報」，代表本機可能中斷或斷網，此時雲端將自動接管通報任務。
- **快速工具**：提供三個一鍵測試按鈕（強制測試發送 LINE/信件、清除重複通報鎖定、重設紀錄分頁欄寬）。

### 2. ⚙️ 系統設定管理 (Settings) (需密碼解鎖)
- **溫度警報閾值設定**：拖曳拉桿調整閾值，支援小數點（如 `28.5`°C）。
- **監測時段設定**：選擇開始與結束小時，自動支援跨夜（如開始 22 點、結束 6 點）。
- **檢查頻率調整**：可調整雲端定時檢查的頻率（10, 15, 30, 60 分鐘）。
- **密碼更改功能**：可在「管理網頁密碼」欄位填入新密碼以進行修改（不修改請留空）。
- **儲存設定**：點擊儲存後，雲端試算表設定檔將同步更新，Apps Script 定時排程亦會自動重建。

### 3. 👥 聯絡人名冊 (Contacts) (需密碼解鎖)
- **快速切換啟用開關**：直接點選表格中的開關（Toggle Switch）即可立即「啟用」或「停用」某聯絡人，系統會即時存檔。
- **新增聯絡人**：點選右上角「新增聯絡收件人」開啟表單，輸入姓名、Email 與 LINE ID。LINE ID 必須以大寫 U (個人)、C (群組) 或 R (聊天室) 開頭。
- **刪除聯絡人**：點擊每列後方的紅色垃圾桶圖示並確認即可移除。

### 4. 📜 歷史通報紀錄 (History Logs)
- **紀錄表格**：顯示當月份 `紀錄_YYYY-MM` 分頁中最新 100 筆數據。
- **篩選與搜尋**：在搜尋框輸入關鍵字（例如時間、超標、LINE、備援、心跳），即可即時過濾表格內容。
- **匯出本頁 CSV**：點擊「匯出本頁 CSV」一鍵將篩選後的紀錄下載為 CSV 格式檔案，方便後續稽核與分析。

## 🛠️ 本機端設定指南

### 1. 配置設定檔 `config.json`
本機程式設定檔位於 `溫度通報/config.json`，請確認以下關鍵設定：
```json

  "tid": "1000704",
  "town_name": "彰化縣線西鄉",
  "temperature_threshold": 28.0,
  "mode": "both",
  "google_sheet_csv_url": "您的Google試算表已發布CSV網址",
  "web_app_url": "您的Google Apps Script網頁應用程式部署網址",
  "line": {
    "enabled": true,
    "channel_access_token": "您的LINE Bot Channel Access Token",
    "to": [
      "U1234567890abcdef...",
      "C10943136364033b..."
    ]
  },
  "email": {
    "enabled": true,
    "smtp_server": "smtp.gmail.com",
    "smtp_port": 587,
    "smtp_user": "您的Gmail信箱@gmail.com",
    "smtp_password": "您的Gmail應用程式16位密碼",
    "to_email": [
      "收件者信箱@gmail.com"
    ],
    "from_email": "您的Gmail信箱@gmail.com"
  }
}
```

### 2. 設定 Windows 排程器自動執行
1. 按 `Win + R` 輸入 `taskschd.msc` 開啟工作排程器。
2. 右側點擊 **「建立基本工作」**，輸入名稱（例如 `環境溫度通報系統`）。
3. 動作選擇 **「啟動程式」**：
   - **程式或指令碼**：填入您的 python 執行路徑（例如 `python`）。
   - **新增引數**：`weather_monitor.py`
   - **開始位置**：`d:\GOOGLE ANGET\溫度通報` (請依據您的實際目錄修改)
4. 在建立後，對工作按右鍵 -> **「內容」**，可於「觸發程序」頁面點選編輯，並勾選「重複工作間隔」為 **「1 小時」**，持續時間為「無限期」，以達到每小時自動執行的效果。
5. *本機排程自動節流*：本機程式會自動讀取 HMI 網頁中設定的「監測頻率」，若檢查間隔時間未到，程式會自動靜默結束，因此本機排程可以設定得比監測頻率更頻繁，系統會自行處理節流。

## 🕹️ 雲端後台管理與進階維護

### 1. 雲端試算表設定 (備用降級機制)
如果因瀏覽器相容性等極端原因無法開啟 HMI 網頁，您仍然可以直接在 Google 試算表中進行管理：
- **`系統設定` 工作表**：包含閾值、監測開始與結束整點、頻率、以及管理網頁密碼（預設 `admin888`，寫在第 5 列）。修改此分頁後，必須點選試算表上方選單 **`🌡️ 溫度通報系統` -> `⚙️ 套用設定並更新排程`** 才能生效。
- **第一工作表 (聯絡人)**：包含姓名、Email、LINE_ID、Enabled（填寫 `N` 或 `No` 代表停用）。
- **`紀錄_YYYY-MM` 工作表**：存放每月通報紀錄與心跳狀態。
  - 表頭欄位：`["通報時間", "溫度閾值設定 (°C)", "通報環境溫度 (°C)", "氣象觀測時間", "警報狀態", "通知狀態"]`

### 2. LINE 自動查詢 ID 功能 (LINE Bot 專屬)
當有新群組或個人加入時，只需在 LINE 聊天室中傳送關鍵字：`id` 或 `查詢id`，LINE 機器人會透過 Webhook 自動將該對象的 `LINE_ID` 寫入試算表第一個分頁的最下方，管理人員可直接複製該 ID 填入 HMI 聯絡人管理介面中。
