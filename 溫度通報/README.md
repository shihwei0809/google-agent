# 彰化縣線西鄉體感溫度監控與通報系統 (多聯絡人/試算表整合版)

此系統用於自動抓取中央氣象署（CWA）的彰化縣線西鄉體感溫度資料。當預報或即時觀測的體感溫度**超過 28°C** 時，自動發送 LINE 訊息與電子郵件通知多位相關人員。

---

## 檔案說明

*   `weather_monitor.py`：主監控腳本。
*   `config.json`：設定檔（存放 LINE 憑證、SMTP 信箱、Google 試算表 CSV 網址與溫度閥值）。
*   `last_notified.json`：狀態記錄檔（自動產生，防止同一天重複發送通知）。

---

## 設定步驟

### 1. 聯絡人來源設定

您可以同時使用**本機設定**與 **Google 試算表**來管理收件人，系統會自動合併兩者的名單：

#### 方法 A：直接在本機 `config.json` 設定
您可以直接編輯 `config.json` 檔案：
*   **LINE 收件人**：在 `"line"` -> `"to"` 欄位中，以列表格式填入 LINE ID，例如：
    `"to": ["U123...", "U456..."]`
*   **Email 收件人**：在 `"email"` -> `"to_email"` 欄位中，以列表格式填入電子郵件，例如：
    `"to_email": ["aaa@gmail.com", "bbb@gmail.com"]`

#### 方法 B：使用 Google 試算表管理（推薦，方便動態修改）
1. 新建一個 **Google 試算表**。
    **試算表欄位規範：**
    *   `Name`：姓名。若填入 **`Threshold`**、**`溫度`**、**`閥值`** 或 **`閾值`**，該列的數值將被解析為新的溫度通報閾值，自動覆蓋本機設定。
    *   `Email`：電子郵件。如果是聯絡人，則填入 Email；如果是溫度閾值列，則填入設定溫度（例如 `29.5`）。
    *   `LINE_ID`：LINE 使用者 ID。格式如 `U` 開頭。
    *   `Enabled`：是否啟用（填入 `Y` 或 `Yes` 表示啟用。若填入 `N` 則不會發送通知給他。若留空預設為啟用）

    **試算表範例：**
    | Name | Email | LINE_ID | Enabled |
    | :--- | :--- | :--- | :--- |
    | **Threshold** | **28.5** | | |
    | 王小明 | xiaoming@gmail.com | U1234567890abcdef1234567890abc | Y |
    | 李四 | lisi@example.com | | Y |
    | 張五 | zhangwu@gmail.com | U9876543210fedcba9876543210fed | N |

    *在上述範例中，警報溫度將會被自動設定為 **`28.5°C`**，且會寄信給王小明與李四，並傳送 LINE 推播給王小明。*

3. 點選試算表左上角：**「檔案」 -> 「共用」 -> 「發布到網路」**。
4. 在彈出視窗中：
   *   將「整個文件」下拉選單改為您建立聯絡人的那張**「工作表」**。
   *   將「網頁」下拉選單改為**「逗號分隔值 (.csv)」**。
   *   點選**「發布」**，並複製產生的網址。
5. 將此 CSV 網址貼入 `config.json` 裡的 `"google_sheet_csv_url"` 欄位。

---

### 2. LINE 憑證設定
*   請將您的 `Channel access token` 填入 `config.json` 內 `"line"` -> `"channel_access_token"`（已預先幫您填入）。
*   *提醒：所有被通知的人，都需要先用 LINE 手機掃描您機器人的 QR Code，並將它加為好友，機器人才能發送訊息給他們。*

### 3. 電子郵件 (SMTP) 設定
以 Gmail 為例，您需要設定「應用程式密碼」：
1. 進入您的 Google 帳戶安全設定，開啟「兩步驟驗證」。
2. 在兩步驟驗證頁面最下方，點擊「應用程式密碼」（App Passwords）。
3. 產生一組給此腳本專用的 16 位數密碼（例如命名為 `溫度通報`）。
4. 將密碼與您的 Gmail 帳號填入 `config.json` 的 `email` 區塊：
   *   `smtp_user`: 您的 Gmail 信箱。
   *   `smtp_password`: 產生的 16 位數密碼（已預先幫您填入）。
   *   `from_email`: 您的 Gmail 信箱。

## 執行與測試

### 1. 手動測試
在終端機（PowerShell 或 CMD）中執行：
```powershell
python weather_monitor.py --force
```
*   `--force` 參數會繞過「一天僅通知一次」的限制，方便進行測試。
*   您可以嘗試在 Google 試算表中修改人員的 `Enabled` 狀態，然後再次執行此命令，檢查終端機印出的 `【聯絡人名單確認】` 是否有即時更新。

### 2. 設定 Windows 排程自動執行
為了讓腳本每天自動運行，可以使用 Windows 內建的「工作排程器」：
1. 按下 `Win + R` 輸入 `taskschd.msc` 打開工作排程器。
2. 在右側欄點擊**「建立基本工作」**。
3. 輸入名稱（例如：`天氣溫度監控通報`），點擊下一步。
4. 觸發程序選擇**「每天」**（或選擇每小時重複，因為腳本內建防重複通知機制，不用擔心被洗版）。
5. 設定您希望的執行時間（建議早上 8:00 執行預報檢查）。
6. 動作選擇**「啟動程式」**。
7. 設定參數：
   *   **程式或指令碼**：`python`
   *   **新增引數**：`weather_monitor.py`
   *   **開始位置**：`d:\GOOGLE ANGET\溫度通報`
8. 點擊完成即可！
